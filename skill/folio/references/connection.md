# 연결 단계에서만 필요한 안내

사람용 집필 본문은 대화 중심이다. 연결되지 않은 작가에게는 현재 사용하는 앱이
로컬 stdio MCP를 지원하는지 확인하고 그 앱의 연결 설정으로 안내한다.

## 현재 구현

Linivera는 로컬 stdio 서버다. 서버는 `node <Linivera 소스 폴더>/bin/linivera-mcp.js`로 실행한다.
Node 24를 권장하며 설치에는 소스 폴더에서 `npm run setup`으로 화면까지 준비한다.
준비된 tarball 설치본은 화면을 포함하므로 setup을 반복하지 않고 `linivera-view`를 쓴다.
설치·연결 검증이 필요하면 MCP 실행 파일이 속한 Linivera 설치 폴더의 `docs/production.md`를 읽는다.
공개 소스와 준비된 패키지는 제공하지만 npm 게시·호스팅 서비스는 제공하지 않는다. 실제 설치본의 README에서 배포 위치를 확인한다.

호스트 스킬은 이 폴더와 references를 함께 설치한다. 도구가 보이는 것과 스킬을
읽은 것을 각각 확인한다. 연결 설정 저장과 실제 도구 호출 성공도 구분한다.

## 업데이트 확인

설치본을 바꿨으면 MCP 서버를 재연결한다. 초기 응답의 serverInfo 이름·버전은 해당 설치 폴더의 package.json과 일치해야 한다. 호스트가 초기 응답을 노출하지 않으면 확인했다고 말하지 말고 연결 로그 확인 방법을 안내한다. 도구 목록과 복사해 둔 스킬을 함께 갱신한다. 판본 선택은 Studio의 읽는 판본 기능이며 UI의 한국어·영어 선택과 다르다. 기존 정적 Studio는 새로 내보낸 뒤 확인한다.

## 저장 위치

현재 대화에서 확인한 작품의 root를 사용한다. 새 작품 또는 위치를 모르는 작품은
작가가 고르거나 확인한 절대 경로가 있어야 한다. 앱에서 폴더 선택이 가능하면
그 경로를 받고 확인하며, 없으면 환경에 맞게 경로를 확인하는 방법을 알려 준다.
도구는 작품 제목만으로 전역 작품 목록을 찾지 않는다.

작가가 로컬 저장을 원하지 않으면 현재 Linivera 단독으로 설치 없는 브라우저·클라우드
서비스를 제공하지 않는다고 설명한다. 저장 권한과 위치를 결정하기 전에 새 작품을 만들지 않는다.

## 완료 기준

실제 Linivera 도구를 사용할 수 있고, 스킬을 읽었고, 작가가 작품 저장 위치를 확인했다.
이후 사람용 안내에서는 작품 제목과 현재 작업 부분으로 대화한다.
