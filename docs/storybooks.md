# 그림책과 동화 쓰기

두 형식은 소설 팩을 사용한다. Folio는 원고·그림 설계와 **공통 자산 관리**를 제공한다.
삽화 생성·시각 검토는 호스트가 수행하고 결과·버전·작가 결정을 Folio에 기록한다.
지면 배치와 인쇄용 파일 제작은 별도다. [그림 연결 방법](assets.md)을 확인한다.

| 형식 | 기본 구조 | 먼저 정할 것 |
|---|---|---|
| 그림책 원고 (`picturebook`) | 책 → 펼침면 | 독자, 함께 읽기 여부, 펼침면 수, 글과 그림의 역할 |
| 동화 (`fairytale`) | 장 → 장면 | 독자, 혼자/함께 읽기, 분량, 인물의 선택과 결말 |

펼침면은 책을 펼쳤을 때 함께 보이는 두 쪽이다. 실제 인쇄 페이지 수와 표지·면지·판권은
제작 단계에서 따로 정한다. 쉬운 설명을 요청했다고 작품의 독자를 5세로 정하지 않는다.

## 그림책 부탁 예시

> Folio로 그림책 원고를 만들자. [독자]가 [혼자 / 함께] 읽을 책이야.
> [주제]를 [펼침면 수]개 펼침면으로 보여 주고 싶어. 정해지지 않은 조건부터 물어봐.
> 인물의 모습과 반복해서 나올 물건을 먼저 정리해 줘.
> 각 펼침면은 ‘읽을 글’과 ‘그림 설명’으로 나누고, 첫 펼침면만 먼저 보여 줘.
> 실제 그림이 없는 상태는 그림 설명이라고 표시해. 저장은 내가 승인한 뒤에 해.

글은 소리·마음·그림에 없는 정보를 맡고, 그림 설명은 위치·표정·보이는 행동을 맡는다.
같은 정보를 전부 반복할 필요는 없다. 페이지를 넘기기 전 궁금한 점과 다음 펼침면의 답을 확인한다.
그림 설명에 나온 제작 지시를 이야기 속에서 실제로 일어난 사건으로 기록하지 않는다.

## 동화 부탁 예시

> Folio로 짧은 동화를 만들자. [독자]가 [혼자 / 함께] 읽을 거야.
> 주인공은 [인물], 바라는 것은 [목표], 어려움은 [장애]야.
> 주인공이 직접 선택해서 끝에 작은 변화를 겪도록 계획해 줘.
> 말투와 결말 분위기는 선택지를 보여 줘. 첫 장면을 읽고 내가 결정할게.

어린 독자라고 자동으로 아기 말투나 훈계를 넣지 않는다.
함께 읽는다면 소리 내어 읽는 호흡을, 혼자 읽는다면 문맥으로 뜻을 이해할 수 있는지 살핀다.

## 검토와 마무리

두 프리셋은 기본 소설 검사와 `novel.young-readers` 검토를 선택한다.
어린 독자 검토는 **실험적 참고 의견**이다. 정확한 원고 인용을 바탕으로 글·그림의 충돌,
독자와 읽기 방식, 인물의 선택 등을 점검하도록 호스트에 요청한다.
이 검토는 독자의 실제 이해도를 보증하지 않으며 원고를 자동 수정하지 않는다.
기존 승인 불가 검사와 영수증·원고 일치 규칙은 그대로 적용된다.

마칠 때는 실제 산출물에 맞춰 “동화 원고 저장” 또는 “그림책 원고와 그림 설명 저장”이라고 확인한다.
그림 설명만으로 삽화가 완성됐다고 안내하지 않는다.
