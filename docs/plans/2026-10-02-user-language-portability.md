# 쉬운 영어 용어와 경로 점검

사용자 요청: 일반 사용자에게 개발 용어 대신 쉬운 영어를 쓰고, 개인 로컬 경로 하드코딩을 확인한다.

## 구현

- Finalize는 검사·승인한 원고 버전의 기록이다. 초안 저장·내보내기·인터넷 공개와 구분한다. Review record, Review needed, Edited since review 등의 대응은 `docs/user-language.md`에 기록했다.
- 뷰어의 메뉴·버튼·상태·단계·내장 검사 설명은 쉬운 영어로 표시한다. 사용자 원고·제목·사용자 검사와 모델의 지적 내용은 원래 언어를 보존한다.
- 기존 내부 id·API enum·파일 형식·라우트·영수증·hash 잠금은 유지한다. 내장 팩 파일을 바꾸지 않아 표시 이름 변경이 팩 digest를 바꾸지 않는다.
- 오류는 뜻과 다음 행동을 먼저 설명하고 정확한 코드와 원래 메시지는 Technical details에 보존한다.
- MCP 도구 14개의 설명과 인자 설명도 영어로 바꿨다. 조건부 입력 계약과 기존 응답은 유지한다.
- 출판 웹·EPUB의 기본 안내와 제목, 미빌드 뷰어의 안내도 영어로 바꿨다.
- 호스트용 스킬에는 사용자 설명과 실제 API 인자를 구분하는 용어 지침을 추가했다.

## 경로 점검

- core, server, bin, scripts, viewer/src의 개인 홈·머신 절대 경로 리터럴: 없음. 작품은 사용자 root, 배포 파일은 모듈 상대 위치, 이식 비교 스크립트는 VIBELORE_ROOT를 사용한다.
- 시작점 ce9b207의 개인 경로가 있던 추적 파일 26개는 AGENTS.md와 개발 계획·판정 기록이었다. 현재 파일에서는 일반 `/path/to/…` 예시로 교체했다. AGENTS.md는 사용자가 지정한 vibelore 체크아웃의 읽기 전용 규칙을 유지한다.
- 현재 추적 파일의 개인 사용자명: 없음. `/Users/x` 등의 보안 테스트용 합성 경로와 일반 예시 경로는 실행 의존성이 아니다.
- Git 과거 이력은 재작성하지 않았다. 이전 버전의 개인 경로는 이력에 남아 있다.
- 원래 작업 폴더와 vibelore 원본은 수정하지 않았다.

## 검증

- 최종 npm run check: lint, typecheck, 1335/1335 통과.
- viewer test: 13/13 통과. 최종 viewer build 성공. 기존 관계도 청크 크기 경고는 유지된다.
- 기존 한국어 도구 설명을 기대한 테스트 2개는 영어 표현으로 변경했고, 조회 범위·enum·required 검증은 유지했다.
- 별도 임시 합성 작품에서 실제 집필·검사·승인·확정을 진행하고, 브라우저에서 Finalized 배지, Review record, Writing steps의 필수 잠금, 영어 검사 설명과 문제 강도를 확인했다.
- git diff --check 통과. 새 표시 모듈은 각각 300줄 미만이다.
- 원격 연결·push·public 전환은 이 요청의 범위에 포함하지 않았다.
