# N7·J4 판정 기록

2026-10-02 사용자가 다음 작업까지 끝까지 진행하도록 지시했다. N7 추천 설계를 승인한 것으로 받아들여 전체 구현 계획, 시험 실행, 구현과 독립 검토, J4 로컬 main 통합을 진행한다. N8은 J4 뒤 별도 계획으로 진행한다. 원격 저장소·배포는 범위 밖이다.

정본 외부 아티팩트는 접근할 수 없어 승인된 로컬 설계·로드맵을 기준으로 한다. 실제 작품을 읽거나 커밋하지 않는다. 별도 합성 fixture와 임시 복사본으로 계획의 전체 코드를 시험한다.

분기 관련 지적은 경로와 엔티티를 포함해 넘김을 식별한다. 경로 참고 버전과 전체 구조 참고 버전은 별도다. 분기 노드 재검사는 같은 커밋의 최신 재검사 refs를 기준으로 삼고 기존 linear/none의 refs 기준은 유지한다.

시험 복사본에서 lint·typecheck·전체 1300/1300개가 통과했다. 그 뒤 추가한 MCP 승인 직전 선택 변경·초기화, 정점/이동/진단 상한과 순환/반환 사건 시험은 15/15개 통과했다. 실제 구현 브랜치의 소스는 계획 단계에서 수정하지 않았다.

가지 fit/review는 `gamebook.parent-fit`, `gamebook.structure-review` 두 실험 참고 검사로 제공한다. 그래프 진단과 팩 검사 지적은 200개 상한과 절단 사유를 기록한다. 비용은 전체 오류를 보려면 순차 수정이 필요하고, 설계 표의 검사 다섯 개보다 실제 팩 검사가 두 개 많다는 점이다.

Task 1 독립 검토에서 계획 제공 코드가 긴 경로 메타데이터의 2MiB 초과와 scope 진단 200개 초과를 허용한 것으로 확인했다. 설계 한도가 우선이다. 경로 전체 바이트를 제한하고 경로를 더 실을 수 없으면 절단·미완료로 남긴다. 마지막 진단 자리는 진단 절단 이유로 예약한다. 비용은 큰 작품에서 한 번에 전달되는 경로가 줄어드는 점이다. 원래 구현자 수정 뒤 독립 범위 재검토를 거친다.

Task 2 독립 검토는 최초 영수증에만 분기 refs가 있었는지 보는 계획 코드가 기능 off→on/none→branching 재검사의 새 refs를 무시하는 것을 재현했다. 이후 선택지 변경을 놓치는 결함이다. 최신 main 재검사에서 새 분기 refs나 명시 분기 문맥을 얻은 경우도 새 refs 기준으로 전환한다. 기존 linear/none만 유지되는 커밋의 의미는 유지한다. 비용은 분기로 전환한 옛 커밋이 정상 재검사로 참고 기준을 갱신한다는 점이다.

Ruling: 최신 경로 사건 또는 초안의 알 수 없는 vital/exists 값은 해당 상태를 unknown으로 바꾸고 BRANCH_STATE_UNKNOWN 참고 지적을 남긴다. 과거 dead/destroyed로 확정 지적하는 계획 코드가 미검증 상태 비확정 계약을 위반했다. 비용: 불명확한 최신 상태가 있는 경로는 작가가 명시 상태를 보완할 때까지 생사·존재 충돌을 확정하지 않는다.
