# 첫 설치·영어 예시·배포 파일 정리

사용자 요청: Vibelore의 설치 안내를 참고해 설치 부담을 줄이고 영어 README와 공개 파일을 새 이름에 맞춘다. Vibelore는 읽기만 한다. CI는 제외한다.

1. 빌드된 GitHub 패키지를 npx로 실행한다. npm 레지스트리 게시를 가정하지 않는다. 단일 linivera 진입점의 기본 실행은 MCP, demo는 새 합성 작품 생성과 Studio, view는 기존 작품 열기다.
2. 영어 CLI 예시를 기본으로 제공하고 --language ko를 지원한다. 기존 runExamples API의 기본 한국어 및 기존 자료·도구 ID는 보존한다.
3. 상세 호스트 지침을 MCP 읽기 전용 리소스로 제공한다. 서버 초기 지침에 인터뷰·실행·실제 사용자 승인·다시 검사 흐름을 포함한다. 별도 스킬 복사 없이 기본 작업을 시작한다.
4. README는 AI 설치 요청 → 호스트별 한 줄 등록 → 영어/한국어 데모 → 실제 작업 순서로 정리한다. 소스 빌드와 절대 경로 편집은 상세 안내로 옮긴다.
5. 새 예시 묶음·패키지는 linivera-* 파일명으로 v0.1.1에 공개한다. 기존 v0.1.0과 원본/봉인 기록은 변경하지 않는다. 영어 안내서는 새 합성 예시로 교체한다.

검증: 실제 stdio 초기화/22개 도구/지침 읽기와 잘못된 URI 차단, 4개 영어 합성 실행 및 한국어 호환, 기존 원고 호환, 새 ZIP 다운로드 경로, tarball 새 설치와 npx 실행, Studio 직접 화면 확인, lint/typecheck/회귀 테스트. 합성 입력만 커밋하며 생성 작품은 릴리스에만 둔다.

완료: README의 등록/데모 명령이 공개 URL에서 실행되고 영어 원고·Studio·Web/EPUB을 확인할 수 있다. 실패 시 이전 명령/패키지로 돌아가며 기존 작품은 변환하지 않는다.
