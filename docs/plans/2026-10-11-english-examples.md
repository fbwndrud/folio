# 영어 예시와 번역 실습 계획

사용자는 영어 README에 맞는 영어 작품 예시와, 구현된 번역 기능이 있으면 실제 번역 흐름 테스트를 요청했다. 번역·개정·요약 판본은 이미 core/variants, packs/variants 및 공개 MCP에 구현돼 있다.

## 산출물

- 새 영어 단편, 그림책(새 삽화), 사람이 읽는 Folio 실습 안내서, 여러 장으로 구성된 이야기. 분량을 측정하며 중편의 상업적 길이를 충족했다고 과장하지 않는다.
- 기존 한국어 단편의 분리된 테스트 사본에 영어 번역 판본. 원본 hash·원본 영수증·용어표를 유지한다.
- 읽기용 Web/EPUB, 읽기 전용 Studio, 원본 데이터가 포함된 이동 가능한 예시 ZIP과 영어 기본 예시 모음.
- 번역의 용어/문단/숫자 검사 및 원본 변경 시 stale, 열린 번역의 원본 변경 승인 차단. 고의 오류는 별도 합성 fixture에서 실행한다.

## 실행과 제한

예시와 생성 이미지는 .local-output/에만 둔다. 코드 테스트에는 작은 합성 입력만 쓴다. 공개 MCP를 경유하여 집필·검토를 기록한다. 분리된 시연 사본의 승인은 모의 승인으로 명시하고 기존 실제 작품에 채택을 추가하지 않는다. 모델 검토는 같은 호스트의 자기검토다. 그림은 호스트에서 생성하고 Folio는 파일·hash·연결·검토를 관리한다.

먼저 확인된 언어 갭을 보완한다: 예시 builder의 내보내기는 현재 main/ko로 고정돼 있으며 ZIP README와 상태 안내도 한국어 우선이다. explicit language/variant 선택과 영문 안내를 지원하되 기존 defaults와 원본 기록장은 유지한다. Studio가 번역 판본을 보여 주지 못하면 그 한계를 표시하고 영어 읽기본과 원본 검토를 구분한다.

검증은 MCP 상태·판본 원본 바인딩·원본 무변경·ZIP/EPUB 및 파일 hash·en 언어 metadata·HTTP·실제 브라우저 렌더링을 포함한다. 결과를 보고 후 기존 v0.1.0 예시를 덮지 않는 별도 예시 산출물로 제공한다. 이번 요청은 새 npm/엔진 버전 게시를 포함하지 않는다.
