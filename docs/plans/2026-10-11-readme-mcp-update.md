# README와 MCP 배포 동기화

## 범위

현재 공개 소스의 판본 선택·번역 출판 기능을 실제 설치 패키지에 포함한다.
영어·한국어 README, 사람용 연결 안내, AI용 연결·화면 지침을 함께 갱신한다.
새 제품 이름은 사용자 선택 전까지 확정하지 않는다.

## 구현 순서

1. 패키지 버전을 0.1.1로 준비하고 MCP initialize의 식별 정보를 package.json에서 읽는다.
2. MCP 초기 안내와 도구 설명에 호스트 책임·사용자 승인·Studio 판본 선택을 반영한다.
3. README에 복사 가능한 stdio 설정, 새 작업 시작, 설치본 갱신·재연결 절차를 넣는다.
4. 실제 tarball 설치본에서 MCP initialize, 도구 호출, Studio 판본 API·내보내기를 검증한다.
5. 이름 선택 후 저장소·배포 이름·사용자 화면을 맞춘다. `.folio`, 기록 hash,
   기존 `folio_*` 도구와 실행 경로는 호환성 대상으로 유지한다. 단순 문자열 전체 치환은 하지 않는다.

## 완료 조건

- MCP가 설치된 package.json과 같은 name/version을 알린다.
- 설치본의 도구 목록과 연결 지침이 최신 화면·판본 기능을 설명한다.
- lint·typecheck·MCP 회귀·viewer 테스트·설치 패키지 검증이 통과한다.
- 실제 작품·이미지·인증 정보가 소스 및 엔진 패키지에 포함되지 않는다.
- 새 이름 확정·게시 전에는 준비된 소스와 공개된 0.1.0 다운로드를 구분한다.

## 마이그레이션과 롤백

작품 형식과 기존 도구 ID는 변경하지 않는다. AI 앱과 Studio를 종료하고 전체 작품 폴더를
백업한 뒤 설치 패키지와 복사해 둔 스킬을 함께 바꾼다. MCP를 재연결해 서버 버전과
도구 목록을 확인하고 작품 조회를 실행한다. 실패하면 이전 설치 폴더와 MCP 실행 경로로
돌아간다. 최초 v0.1.0 태그·배포 파일·예시 다운로드는 덮어쓰지 않는다.
