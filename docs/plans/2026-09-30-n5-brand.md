# Folio N5 브랜드 세트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 회사 문서(제품 소개서·브로셔)를 위한 둘째 팩 `packs/brand`를 만든다. 세트는 브랜드 어조(`brand.voice`: 어조 모델 검사 + 과장·단정 금지 표현)와 수치 대조(`brand.figures`: N2 `sources` 검사 재사용 + 단위 대조)다. N2 `sources.numbers-match`의 숫자 읽기 오탐(NFKC, 날짜, 1.50 ≠ 1.5)을 고친다. 코어는 바꾸지 않는다.

**Architecture:**
- `packs/brand`는 `packs/sources`처럼 단계·프리셋 없는 둘째 팩이다(`pack.yaml` + 검사 지시 글 + 이름으로 등록한 검사기). 검사 `config`는 소설 팩의 `withCheckConfig`로 검사기 둘째 인자에 넘긴다.
- 수치 대조는 새로 만들지 않고 재사용한다. 세트 `brand.figures`가 `sources.claim-supported`·`sources.numbers-match`를 멤버로 담고, 새 검사 `brand.figure-units`는 `packs/sources/checkers/claims.js`의 `claimsOf`·`numberMatches`를 import한다. 주장은 작품 `packs`에 `sources`가 있을 때만 요청되므로 브랜드 작품은 `packs: [knowledge, sources, brand]`다.
- 어조는 모델 검사(`brand.tone`, 인용 필수)다. 기준은 payload에 이미 있는 윗계획(`upperPlans`)과 `brief`의 어조 지침이다. 금지 표현은 사용자 검사 `words`와 같은 방식의 결정론 검사이고, 작품마다 다른 목록은 사용자 검사(`words`·`pattern`)로 더한다.
- 완료 기준은 MCP stdio로 확인한다(`test/acceptance/n5.test.js`).

**Tech Stack:** Node ESM + JSDoc, `node:test`, `yaml`, `@modelcontextprotocol/sdk`(1.x, stdio), ESLint 9 + TypeScript(`checkJs`).

**Spec:** 이 계획의 "설계 요약"과 "결정" 절이 N5 설계다. 사용자가 바빠 묻지 않기로 했으므로(2026-09-30 지시) 브레인스토밍에서 물을 곳은 추천안을 골랐고, 결정 표에 "추천 채택(사용자 확인 필요)"으로 적었다. 별도 spec 파일은 없다.
- 설계 정본: 아티팩트 https://claude.ai/artifact/WjJzcsjnQZnVxyyJZaxvcX §03(회사 제품 소개서·브로셔 행), §12(검사 세트 "회사 문서: 브랜드 어조 · 수치 대조", 사용자 검사 세 방식), §13(자료와 근거), §14(팩). 계획 세션에서 Artifact read로 읽었다.

## 설계 요약

- **팩 모양:** `packs/brand` — `pipelines`·`presets`·`prompts`·`defaultCheckSets` 없음. 검사 셋, 세트 둘.

  | 검사 | 종류 | 단계 | 보는 것 | 지적 코드 |
  |---|---|---|---|---|
  | `brand.tone` | 모델, `requireQuote` | critic | 윗계획·brief의 어조 지침(없으면 높임 체 섞임·반말·겹친 감탄)과 어긋나는 문장 | 모델이 정함 |
  | `brand.banned-phrases` | 결정론 | facts | `config.words`(과장·단정 기본 목록)가 원고(NFC)에 있음. `config.allow`(최고경영자 등) 안의 자리는 셈하지 않음. 표현마다 한 번, `count` | `BANNED_PHRASE` |
  | `brand.figure-units` | 결정론 | facts | 주장 숫자가 연결된 자료 인용에는 다른 단위로만 있음(`config.units`). 자료에 그 숫자가 없거나 단위 없는 같은 숫자가 있으면 알리지 않음 | `UNIT_NOT_IN_SOURCE` |

  | 세트 | 멤버 | 추천 |
  |---|---|---|
  | `brand.voice`(브랜드 어조) | `brand.tone`, `brand.banned-phrases` | kinds `company`, `brochure` |
  | `brand.figures`(수치 대조) | `sources.claim-supported`, `sources.numbers-match`, `brand.figure-units` | kinds `company`, `brochure`. `sources` 팩이 없으면 `CONFIG_INVALID`(`CHECK_UNKNOWN`) |

- **숫자 읽기(`packs/sources/checkers/claims.js`, N2 미룬 minor):** NFKC를 버리고 전각 숫자·쉼표·마침표만 반각으로 바꾼다. 천 단위 쉼표는 빼고, 그 밖의 쉼표(나열)와 마침표 둘 이상(날짜·판 번호)은 나눈다. 앞의 0과 소수점 뒤 끝 0을 뗀다(`07` → 7, `1.50` → 1.5, `2.0` → 2). 문자열이 아니면 빈 목록(모양 틀린 연결에서 던지지 않음). `sources` 팩 `version`을 2로 올린다.
- **어조 지침 자리:** 맨 위 노드의 계획 글(예: `어조: 존댓말(합니다체), 짧은 문장, 감탄 없이.`). 계획 승인 때 작가가 본다. 예시 글·긴 규칙은 사용자 검사(`source`·`samples`, §12 방법 1·2).
- **금지 표현:** 팩 목록은 과장·단정 표현(표시·광고에서 근거가 필요한 말)이다. 작품별 금지어는 팩 설정을 바꿀 수 없으므로 자기 id를 가진 사용자 검사(`words`·`pattern`, §12 방법 3)로 더한다.
- **회사 문서 프리셋:** 만들지 않는다. `folio_init { preset: 'guide', packs: ['knowledge', 'sources', 'brand'] }`로 만들고 세트는 첫 설정 인터뷰에서 고른다(`folio_config { workKind: 'company' }` 추천). 새 첫 팩도 만들지 않는다 — §03 "추가로 필요한 것"은 "브랜드 세트 + 내보내기"뿐이다.
- **토글:** 새 기능(`features`)은 없다. 검사는 `packs`, `checkSets`, `checks.<id>.mode: off`로 켜고 끈다. 잠금은 토글이 아니다.
- **완료 기준(`test/acceptance/n5.test.js`, MCP stdio):**
  - N5-1: `guide` 프리셋 + brand 팩으로 작품을 만들고, `folio_config { workKind: 'company' }`가 두 세트를 추천만 한다(고르지 않음). `packPresets`에 brand가 없다.
  - N5-2: `brand.voice`의 금지 표현이 참고 의견으로 나오고, 어조 검사 요청에 어조 줄이 실리며, 원고에 없는 인용은 버려진다. 사용자 금지어 검사가 옆에서 돈다.
  - N5-3: `brand.figures`가 틀린 단위·자료에 없는 숫자·근거 없는 주장을 잡고, 나눈 날짜·㎡는 잡지 않는다.
  - N5-4: block으로 올리면 막히고 넘기려면 이유가 필요하다. hard는 거부된다.
  - N5-5: `sources` 팩 없이 `brand.figures`는 거부된다. 세트·`mode: off`로 끄면 돌지 않는다. `core.promise-order` 잠금은 그대로다.
- **범위 밖:** 지면·내보내기(N8), 단위 환산(3천만 = 30,000,000), 한글 수사, 작품별 팩 검사 설정(인계 H1), 회사 문서 전용 프롬프트.

```js
export const claimsOf = (ctx) => (Array.isArray(ctx?.claims) ? ctx.claims : [])
  .filter((claim) => claim && typeof claim.quote === 'string' && Array.isArray(claim.sources));

/** 주장이 연결한 자료 id(한 번씩, 처음 나온 순서). */
export const sourceIdsOf = (claim) => [...new Set(claim.sources.map((link) => link?.sourceId).filter((id) => typeof id === 'string'))];

/** 자료 설명서의 신뢰도(다듬고 소문자로). 자료가 없거나 적지 않았으면 null. */
export function reliabilityOf(ctx, sourceId) {
  const value = ctx?.work?.sources?.get?.(sourceId)?.reliability;
  return typeof value === 'string' ? value.trim().toLowerCase() : null;
}

/** 전각 숫자·쉼표·마침표만 반각으로 바꾼다. NFKC 는 쓰지 않는다 — ㎡·²·① 같은 기호가 숫자가 되면 오탐이 난다(N2 미룬 minor). */
const toHalfWidth = (text) => text.replace(/[０-９，．]/g, (ch) => String.fromCharCode(ch.charCodeAt(0) - 0xfee0));

/** 앞의 0을 떼고(07 → 7) 소수점 뒤 끝 0을 뗀다(1.50 → 1.5, 2.0 → 2). */
const canonical = (part) => {
  const trimmed = part.replace(/^0+(?=\d)/, '');
  return trimmed.includes('.') ? trimmed.replace(/0+$/, '').replace(/\.$/, '') : trimmed;
};

/**
 * 글에서 읽은 숫자 한 덩어리를 값 목록으로 바꾼다.
 * 천 단위 쉼표(1,000 → 1000)는 뺀다. 그 밖의 쉼표는 나열로 보고 나눈다(1,2,3 → 1, 2, 3).
 * 마침표가 둘 이상이면 날짜·판 번호로 보고 나눈다(2026.09.30 → 2026, 9, 30).
 */
function valuesOf(raw) {
  if (/^\d{1,3}(,\d{3})+(\.\d+)?$/.test(raw)) return [canonical(raw.replace(/,/g, ''))];
  return raw.split(',').flatMap((piece) => ((piece.match(/\./g) ?? []).length > 1 ? piece.split('.') : [piece])).filter(Boolean).map(canonical);
}

/**
 * 글 속 아라비아 숫자(연도 포함)의 값과 그 덩어리가 끝나는 곳(단위를 읽을 자리). 나온 순서대로, 겹쳐도 모두.
 * 문자열이 아니면 빈 목록이다. 한글 숫자(삼십칠조)는 읽지 않는다(N2 결정 11).
 * @param {unknown} text
 * @returns {Array<{ value: string, end: number }>}
 */
export function numberMatches(text) {
  if (typeof text !== 'string') return [];
  const half = toHalfWidth(text);
  return [...half.matchAll(/\d+(?:[.,]\d+)*/g)].flatMap((match) => {
    const end = (match.index ?? 0) + match[0].length;
    return valuesOf(match[0]).map((value) => ({ value, end }));
  });
}

/**
 * 글 속 아라비아 숫자 값을 한 번씩, 나온 순서로. 전각 숫자(２０２６)는 반각으로 읽는다.
 * @param {unknown} text
 */
export const numbersIn = (text) => [...new Set(numberMatches(text).map((match) => match.value))];
```

```js
/** 설정 목록에서 빈 값이 아닌 문자열만 NFC 로 받는다. */
const phrasesOf = (value) => (Array.isArray(value) ? value.filter((item) => typeof item === 'string' && item.trim()).map((item) => item.normalize('NFC')) : []);

/** text 속 needle 의 시작 위치 전부. */
function positionsOf(text, needle) {
  const found = [];
  for (let at = text.indexOf(needle); at !== -1; at = text.indexOf(needle, at + 1)) found.push(at);
  return found;
}

/** 허용 표현(예: 최고경영자)이 덮는 글자 범위. */
const allowedSpans = (text, allow) => allow.flatMap((phrase) => positionsOf(text, phrase).map((start) => [start, start + phrase.length]));

/**
 * 금지 표현(brand.banned-phrases). 사용자 검사의 words 와 같은 방식이다: 원고(NFC)에 그 표현이 그대로 있으면 표현마다 한 번 알린다.
 * 목록은 pack.yaml config.words(과장·단정 표현 기본 목록), 허용 표현은 config.allow 다. 허용 표현 안에 든 자리는 세지 않는다.
 * 작품마다 다른 금지 표현은 사용자 검사(words·pattern)로 더한다 — 팩 검사의 설정은 작품별로 바꿀 수 없다.
 * 등급은 pack.yaml(advisory)과 작가 설정이 정한다. 지적에 severity 를 적지 않는다.
 * @param {{ draft?: unknown }} ctx
 * @param {{ words?: unknown, allow?: unknown }} [config]
 */
export function bannedPhrases(ctx, config = {}) {
  const draft = typeof ctx?.draft === 'string' ? ctx.draft.normalize('NFC') : '';
  const spans = allowedSpans(draft, phrasesOf(config.allow));
  const findings = [];
  for (const phrase of new Set(phrasesOf(config.words))) {
    const count = positionsOf(draft, phrase).filter((start) => !spans.some(([from, to]) => start >= from && start + phrase.length <= to)).length;
    if (count === 0) continue;
    findings.push({ code: 'BANNED_PHRASE', quote: phrase, count, message: `금지 표현 "${phrase}"(${count}번): 근거 없이 쓰면 과장·단정이 된다` });
  }
  return findings;
}
```

```js
import { claimsOf, numberMatches } from '../../sources/checkers/claims.js';

/** config.units({ 대표 단위: [표기, ...] })를 [표기, 대표 단위] 목록으로 편다. 긴 표기부터 본다(개월이 개보다 먼저). */
function aliasesOf(units) {
  if (!units || typeof units !== 'object' || Array.isArray(units)) return [];
  const pairs = Object.entries(units).flatMap(([unit, spellings]) => (Array.isArray(spellings) ? spellings : [])
    .filter((spelling) => typeof spelling === 'string' && spelling).map((spelling) => [spelling.normalize('NFC'), unit]));
  return pairs.sort((a, b) => b[0].length - a[0].length);
}

/** 숫자 덩어리 바로 뒤(빈칸 하나까지 건너뜀)의 단위. 날짜처럼 한 덩어리에서 나온 값은 마지막 값만 단위를 읽는다. */
function figuresIn(text, aliases) {
  const normal = typeof text === 'string' ? text.normalize('NFC') : '';
  const matches = numberMatches(normal);
  return matches.map((match, index) => {
    if (matches[index + 1]?.end === match.end) return { value: match.value, unit: null };
    const rest = normal.slice(match.end).replace(/^[ \t]/, '');
    return { value: match.value, unit: aliases.find(([spelling]) => rest.startsWith(spelling))?.[1] ?? null };
  });
}

/**
 * 수치 단위 대조(brand.figure-units). 주장 인용의 숫자가 연결된 자료 인용에도 있지만 그 자리에서는 늘 다른 단위일 때 알린다
 * (예: 주장 "30%", 자료 "30억"). 자료에 그 숫자가 없으면 sources.numbers-match 몫이라 건너뛴다. 자료 쪽에 단위 없는 같은 숫자가
 * 하나라도 있으면 알리지 않는다(단위를 모르면 틀렸다고 하지 않는다). 근거 없는 주장은 sources.claim-supported 몫이다.
 * 단위 표기 목록은 pack.yaml config.units. 등급은 pack.yaml(advisory)과 작가 설정이 정한다. 지적에 severity 를 적지 않는다.
 * @param {{ claims?: unknown }} ctx
 * @param {{ units?: unknown }} [config]
 */
export function figureUnits(ctx, config = {}) {
  const aliases = aliasesOf(config.units);
  const findings = [];
  for (const claim of claimsOf(ctx)) {
    if (claim.sources.length === 0) continue;
    const backed = claim.sources.flatMap((link) => figuresIn(link?.quote, aliases));
    const figures = [];
    for (const { value, unit } of figuresIn(claim.quote, aliases)) {
      if (unit === null) continue;
      const same = backed.filter((figure) => figure.value === value);
      if (same.length === 0 || same.some((figure) => figure.unit === null || figure.unit === unit)) continue;
      figures.push({ number: value, unit, sourceUnits: [...new Set(same.map((figure) => figure.unit))] });
    }
    if (figures.length === 0) continue;
    const told = figures.map((f) => `${f.number}${f.unit}(자료: ${f.sourceUnits.map((u) => `${f.number}${u}`).join(', ')})`).join(', ');
    findings.push({ code: 'UNIT_NOT_IN_SOURCE', quote: claim.quote, figures, message: `"${claim.quote}": ${told} — 단위가 연결된 자료 인용과 다르다` });
  }
  return findings;
}
```

```js
/** MCP 너머의 가짜 호스트 모델. 검사는 critic 지적(있으면)으로 답하고, 수정 요청에는 같은 원고를 돌려준다. */
function answerer({ draft = '본문.', claims = null, events = [], critic = [] } = {}) {
  return (request) => {
    const p = request.payload;
    if (request.purpose === 'check') return JSON.stringify({ checked: p.checks.map((c) => c.checkId), findings: p.step === 'critic' ? critic : [] });
    if (request.purpose === 'revise' || request.purpose === 'user_revision') return p.draft;
    if (p.produces === 'plan') return `${p.node.title || p.node.id} 계획`;
    if (p.produces === 'draft') return draft;
    if (p.produces === 'events') return JSON.stringify({ events, appearances: [], mentions: [], ...(claims ? { claims } : {}) });
    throw new Error(`no answer for ${request.purpose}/${p.produces}`);
  };
}

async function ok(promise) {
  const out = await promise;
  assert.equal(out.ok, true, JSON.stringify(out.error));
  return out.result;
}

/** 작가 질문(needs_user)까지 overview 를 MCP 로 돌린다. 지나온 결과 이름과 요청을 모은다. */
async function driveOverview(folio, root, answer) {
  const labels = [];
  const requests = [];
  let out = await ok(folio.call('folio_run', { root, node: 'overview' }));
  for (let i = 0; i < 40; i += 1) {
    labels.push(label(out));
    if (out.status !== 'needs_model') return { labels, requests, out };
    requests.push(...out.requests);
    out = await ok(folio.call('folio_resume', { root, runId: out.runId, answers: Object.fromEntries(out.requests.map((r) => [r.requestId, answer(r)])) }));
  }
  throw new Error('drive did not finish');
}
```
