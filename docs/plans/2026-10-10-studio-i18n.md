# Studio 한국어·영어 선택

사용자 요청: 현재 영어 UI에 한국어/영어 선택을 추가한다.

- 공통 번역 사전과 React 언어 컨텍스트. 다른 언어는 사전과 지원 목록에 추가 가능.
- 모든 화면 상단에 언어 선택. 명시적 선택은 브라우저에 저장, 최초에는 지원되는 브라우저 언어 사용, 없으면 영어.
- 메뉴·상태·도움말·오류 안내·검사 이름·접근성 이름 번역. 원고·제목·인용·사용자 정의 규칙·원본 코드/ID는 그대로.
- 내보낸 검토 사본도 같은 선택 지원. 읽기 설정과 언어 설정은 독립.
- 확인: 사전 누락/보간/설정 저장 실패/사용자 내용 보존/필수 검사 표시 회귀, 기존 viewer 테스트와 빌드, 실제 브라우저 전환·새로고침·메뉴·상세·모바일·정적 사본.
- 데이터 이전 없음. 이전 UI로 되돌려도 원고·검토 기록·승인 규칙에 영향 없음.

## 완료 및 검증

- 화면 상단 한국어/English 선택과 명시적 선택 저장을 구현했다. UI 컨텍스트 변경으로 현재 화면을 갱신한다.
- 메뉴, 상태, 안내, 기술 상세 제목, 기본 검사 그룹/검사, 읽기 설정, 도표 조작 이름을 연결했다. 사용자 정의 명칭·본문·인용·진단 코드·ID는 보존한다.
- 한국어/영어 메뉴 12종씩 실제 브라우저 확인. 원고에서 영어 전환 전후 본문 일치 확인. 새로고침 후 영어 선택 유지 확인.
- 검토 상세 단계/결과/작가 승인·자기검토 안내, 기본 검사 이름과 필수 hard 표시를 한국어로 확인.
- 390px 한국어/영어 화면 폭 390px: 언어 선택기와 메뉴 수평 넘침 없음. 검증 viewport 종료 전 초기화.
- 내보낸 읽기 전용 사본에서 한국어→영어→새로고침→한국어 전환 확인. 기존 5개 검토 사본에 최신 UI 반영.
- viewer 테스트 63개(새 i18n 9개 포함), build, lint, typecheck, diff 검사와 설치 패키지 검증 통과.
- 중편 138개/설명서 22개 원본 파일 hash 재대조: 변경 없음. 데이터 포맷·승인/잠금 계약 변경 없음.
- 증거는 무시된 `.local-output/i18n-tooling/` 실행 로그 및 `.local-output/ui-audit-20261010/i18n-*` 화면/메뉴 기록에 보관.

지원 언어는 현재 한국어와 영어다. 이전에 내려받은 검토 사본은 새로 내보내야 이 선택기가 포함된다. 실제 사용자 문구 선호와 스크린리더 사용성 전체를 검증했다는 의미는 아니다.
