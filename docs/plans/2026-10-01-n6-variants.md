# Folio N6 판본 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 커밋된 원본 잎 하나에서 판본(번역·개정·요약)을 만든다.
- 판본마다 검사와 영수증이 따로 있다.
- 원본 대비 검사를 둔다: 블록·숫자·문단·용어(결정론), 누락·추가(모델). 모두 실험·참고 의견이다.
- 판본 키가 없는 기존 영수증·기록은 `main`으로 읽는다.
- hash 일치와 영수증 잠금은 판본마다 따로 성립한다. 한 판본의 영수증으로 다른 판본(또는 원본)을 커밋할 수 없다.
- 기록장은 추가만 한다.
- 먼저 코어 정리를 한다: `runner.js`를 나누고, 근거 기록장 손상 동작을 검토한다.

**Architecture:**
- 판본 글은 `variants/<판본 id>/<노드 id>.md`에 있다. 트리 폴더와 떨어져 있어 노드를 옮기거나 묶어도 그대로다. 용어 대응표는 `variants/<판본 id>/terms.yaml`이다.
- 판본은 work.yaml `variants`에 지도로 선언한다: `{ id, kind: translation|revision|summary, lang?, steps? }`. `main`은 늘 첫째다.
- 판본 파이프라인은 코어가 정한다(`core/variants/pipeline.js`): `draft → variant-checks → variant-review → revise → approve → commit`. 커밋은 잠긴다. 판본 digest는 팩 digest와 판본 선언(id·종류·언어)을 묶는다.
- 판본 실행은 `folio_run { variant }`로 시작한다. 잎만, `mode: normal`만 된다. 원본이 커밋 그대로여야 시작된다.
- 판본 영수증은 `variant`와 `original: { receiptId, committedHash }`(검사할 때 본 원본 커밋)를 든다. 사건·자식 목록은 들 수 없다. 커밋은 판본 파일만 쓴다.
- 판본 검사는 둘째 팩 `packs/variants`가 준다. 검사는 `variant-checks`·`variant-review` stage에만 붙는다. 원본 실행에는 걸리지 않는다.
- `folio_status.variants`는 판본마다 `{ committed, stale, drift, missing }`이다. 원본의 stale·drift와 섞지 않는다.
- 새 모듈은 모두 `core/`·`packs/`에 있고 모델·네트워크를 부르지 않는다.

**Tech Stack:** Node ESM + JSDoc, `node:test`, `yaml`, `@modelcontextprotocol/sdk`(1.x, stdio), ESLint 9 + TypeScript(`checkJs`).

**Spec:** 이 계획의 "설계 요약" 절이 N6 설계다. 사용자 브레인스토밍 없이 계획 세션이 추천안을 골랐다(사용자가 바쁘니 묻지 말라고 했다). 고른 것은 모두 결정 표에 "추천 채택(사용자 확인 필요)"로 적었다.
- 설계 정본: 착수 계획서 아티팩트 §03(번역본·개정판 행), §04 판본, §09 잠금 규칙.

## 설계 요약

### 저장

- 판본 글: `variants/<id>/<노드 id>.md`(앞머리 + 본문). 노드 id로 찾으니 트리 이동·묶기와 상관없다. `store/tree.js`는 바꾸지 않는다(트리 읽기와 판본 읽기를 섞지 않는다).
- 용어 대응표: `variants/<id>/terms.yaml`, `terms: [{ from, to }]`. 파일 hash가 `rev`다.
- 읽기는 `features.variants`가 켜졌을 때만 한다.
- 경고: 선언하지 않은 판본 폴더(`VARIANT_DIR_UNDECLARED`), 이름이 노드 파일 꼴이 아닌 파일(`VARIANT_FILE_STRAY`), 트리에 없는 노드의 파일(`VARIANT_NODE_MISSING`).
- 오류(`WORK_INVALID`): `variants/`·판본 폴더·판본 파일이 링크(`VARIANTS_DIR_INVALID`·`VARIANT_DIR_INVALID`·`VARIANT_FILE_INVALID`), 용어 대응표 모양이 틀림(`VARIANT_TERMS_INVALID`). 작품 밖 글을 판본으로 받지 않는다.

### 선언과 파이프라인

- `variants: [main, { id: en, kind: translation, lang: en }]`. 문자열 항목은 `main`만 된다. 다른 문자열은 예전처럼 `VARIANT_UNSUPPORTED`다.
- 판본 파이프라인은 코어가 정한다. 첫 팩의 단계·프롬프트를 쓰지 않는다. `steps`는 있는 단계만 덮어쓴다(`VARIANT_STEP_UNKNOWN`). `commit`은 잠긴다.
- 판본 digest = `sha256({ packs: 팩 digest, variant: { id, kind, lang } })`. 같은 단계라도 판본이 다르면 digest가 다르다.
- 판본 검사는 stage(`variant-checks`·`variant-review`)로 판본 파이프라인에만 붙는다. 판본을 선언하지 않은 작품도 판본 팩 검사를 둘 자리가 있다(`homes`).

### 실행

- `folio_run { root, node?, variant }`. `node`가 없으면 읽는 순서로 첫 잎 중 원본이 커밋 그대로이고 그 판본 커밋이 없는 것.
- 거부: 선언 없음(`VARIANT_UNKNOWN`), 기능 꺼짐(`FEATURE_DISABLED`), 재검사·다시 커밋(`VARIANT_MODE_UNSUPPORTED`), 가지(`VARIANT_LEAF_ONLY`), 원본 미커밋(`VARIANT_ORIGINAL_NOT_COMMITTED`), 원본 손수정(`VARIANT_ORIGINAL_DRIFTED`).
- 열린 판본 실행은 그 판본 요청으로만 이어진다. main 요청은 그것을 이어받지 않는다(`RUN_IN_PROGRESS`).
- 실행 도중 원본이 바뀌면(다시 커밋·손수정) `VARIANT_ORIGINAL_CHANGED` 질문: 승인·고쳐 쓰기 불가, skip만.
- 실행 도중 판본 파일을 손으로 고치면 C0 손수정 점검이 판본 파일을 본다(`NODE_TEXT_CHANGED`, skip만).
- 요청 payload: `variant`, `original`, `terms`, `current`, `draft`, 원고 요청에만 `instructions`(종류별, 코어가 정한다).

### 영수증과 잠금

- 판본 영수증: `variant`, `original: { receiptId, committedHash }`, `events: []`, `structure` 없음, `refs: [{ kind: 'original' }, { kind: 'terms' }]`.
- `original`은 커밋 때 기록장에서 다시 정한다(실행 파일을 믿지 않는다).
- 커밋 잠금 순서: 형식(`validateReceipt`, 작품이 선언한 판본만) → 파이프라인 digest + `pipeline.variant === receipt.variant` → 결정 기록장 대조 → 원본 결속(`LOCK_ORIGINAL_CHANGED`) → 판본별 supersede·already.
- 판본 커밋은 판본 파일만 쓴다. 사건·등장 위치·근거 기록장에 아무것도 더하지 않는다. 커밋 기록은 `variant`를 든다.
- `variantOf(record)`: 키가 없으면 `main`. N6 전에 쓰인 영수증·커밋·재검사 기록이 그대로 읽힌다.

### 팩과 상태

- `packs/variants`: `variants.blocks-kept`, `variants.numbers-kept`(sources 팩의 숫자 읽기 재사용), `variants.paragraphs`, `variants.terms`(결정론), `variants.fidelity`(모델, 원고 인용 필수 아님). 모두 experimental advisory. 기본 세트 `variants.basic`.
- `folio_status.variants`: `{ <id>: { committed, stale, drift, missing } }` 또는 `null`(기능 꺼짐·판본 없음). `activeRun.variant`. 실행 중 손수정 drift(`CHANGED_DURING_RUN`)에 `variant`.

### 코어 정리 (A1)

- `runner.js`를 나눈다: 기록장·문맥 읽기는 `run-context.js`, 새 실행·같은 요청 판단은 `run-start.js`. 212→175줄.
- 근거 기록장 손상(N2 미룬 minor): fail-closed(`LEDGER_TAMPERED`)는 그대로 둔다. 대신 `details`에 어느 기록장인지, 어떤 기능인지, 할 수 있는 일(백업에서 되살리기, 그 기능 끄기)을 싣는다.
- 쓰이지 않는 `recommitTextChanged`(C0가 `text-guard.js`로 대신함)를 지운다.
- `isPlainObject` 중복은 C0가 이미 모았다. 다시 하지 않는다.

````js
import { isPlainObject } from '../util/plain.js';
import { MAIN, VARIANT_ID, VARIANT_KINDS } from './model.js';

const FIELDS = ['id', 'kind', 'lang', 'steps'];
const LANG_MAX = 35;

/**
 * work.yaml variants: [main, { id, kind, lang?, steps? }, ...]. main 은 늘 첫 자리에 있다(적지 않아도).
 * 문자열 항목은 main 만 된다 — 다른 판본은 종류(kind)가 있어야 해서 지도로 적는다(문자열은 예전처럼 VARIANT_UNSUPPORTED).
 * steps 는 판본 파이프라인 덮어쓰기(core/variants/pipeline.js 가 검사한다). 오류는 errors 에 넣고 던지지 않는다.
 * @param {unknown} input
 * @param {Array<Record<string, unknown>>} errors
 */
export function readVariantDecls(input, errors) {
  const ids = [MAIN];
  /** @type {Record<string, { id: string, kind: string, lang: string|null, steps: Record<string, any> }>} */
  const specs = {};
  if (input === undefined) return { ids, specs };
  if (!Array.isArray(input)) { errors.push({ code: 'VARIANTS_INVALID' }); return { ids, specs }; }
  for (const entry of input) {
    if (entry === MAIN) continue;
    if (typeof entry === 'string') { errors.push({ code: 'VARIANT_UNSUPPORTED', variant: entry, hint: 'declare a variant as a map: { id, kind: translation|revision|summary, lang? }' }); continue; }
    if (!isPlainObject(entry)) { errors.push({ code: 'VARIANTS_INVALID' }); continue; }
    const unknown = Object.keys(entry).filter((key) => !FIELDS.includes(key));
    if (unknown.length) errors.push({ code: 'VARIANT_FIELD_UNKNOWN', fields: unknown });
    const { id, kind, lang, steps } = entry;
    if (typeof id !== 'string' || id === MAIN || !VARIANT_ID.test(id)) { errors.push({ code: 'VARIANT_ID_INVALID', variant: typeof id === 'string' ? id.slice(0, 60) : null }); continue; }
    if (Object.hasOwn(specs, id)) { errors.push({ code: 'VARIANT_DUPLICATE', variant: id }); continue; }
    if (!VARIANT_KINDS.includes(kind)) errors.push({ code: 'VARIANT_KIND_INVALID', variant: id });
    if (lang !== undefined && (typeof lang !== 'string' || !lang.trim() || lang.length > LANG_MAX)) errors.push({ code: 'VARIANT_LANG_INVALID', variant: id });
    if (steps !== undefined && !isPlainObject(steps)) errors.push({ code: 'VARIANT_STEPS_INVALID', variant: id });
    ids.push(id);
    specs[id] = { id, kind, lang: typeof lang === 'string' ? lang : null, steps: isPlainObject(steps) ? structuredClone(steps) : {} };
  }
  return { ids, specs };
}
````

````js
import { sha256 } from '../util/hash.js';
import { parseYaml } from '../util/yaml.js';
import { isPlainObject } from '../util/plain.js';
import { parseDoc, serializeDoc } from './frontmatter.js';
import { ID } from './ids.js';

export const VARIANTS_DIR = 'variants';
export const TERMS_FILE = 'terms.yaml';
const TERM_MAX = 200;
const MD = /^(.+)\.md$/;

/** @typedef {{ nodeId: string, path: string, title: string|null, data: Record<string, any>, body: string }} VariantText */
/** @typedef {{ id: string, texts: Map<string, VariantText>, terms: { rev: string|null, pairs: { from: string, to: string }[] } }} VariantStore */

/** 링크를 따라가지 않고 본다. 없으면 null. */
async function entryKind(path) {
  try {
    const info = await lstat(path);
    return info.isSymbolicLink() ? 'link' : info.isDirectory() ? 'dir' : info.isFile() ? 'file' : 'other';
  } catch (error) {
    if (/** @type {NodeJS.ErrnoException} */ (error).code === 'ENOENT') return null;
    throw error;
  }
}

/** terms.yaml: { terms: [{ from, to }] }. from·to 는 비지 않은 글(200자까지). 틀리면 null. */
function readTerms(text) {
  let raw;
  try { raw = parseYaml(text, { source: TERMS_FILE }); } catch { return null; }
  if (!isPlainObject(raw) || !Array.isArray(raw.terms) || Object.keys(raw).some((key) => key !== 'terms')) return null;
  const ok = (value) => typeof value === 'string' && value.trim() !== '' && value.length <= TERM_MAX;
  if (!raw.terms.every((t) => isPlainObject(t) && ok(t.from) && ok(t.to) && Object.keys(t).every((key) => key === 'from' || key === 'to'))) return null;
  return raw.terms.map((t) => ({ from: t.from, to: t.to }));
}

/** 판본 하나의 폴더: <노드 id>.md(판본 본문)와 terms.yaml(용어 대응표). */
async function readVariantDir(root, id, tree, errors, warnings) {
  /** @type {VariantStore} */
  const store = { id, texts: new Map(), terms: { rev: null, pairs: [] } };
  const dir = join(root, VARIANTS_DIR, id);
  const kind = await entryKind(dir);
  if (kind === null) return store;
  if (kind !== 'dir') { errors.push({ code: 'VARIANT_DIR_INVALID', path: `${VARIANTS_DIR}/${id}` }); return store; }
  for (const entry of await listEntries(dir)) {
    const path = `${VARIANTS_DIR}/${id}/${entry.name}`;
    if (entry.name === TERMS_FILE) {
      if (!entry.isFile()) { errors.push({ code: 'VARIANT_TERMS_INVALID', variant: id, path }); continue; }
      const text = await readFile(join(dir, entry.name), 'utf8');
      const pairs = readTerms(text);
      if (!pairs) errors.push({ code: 'VARIANT_TERMS_INVALID', variant: id, path });
      else store.terms = { rev: sha256(text), pairs };
      continue;
    }
    const match = MD.exec(entry.name);
    if (!match || !ID.test(match[1])) { warnings.push({ code: 'VARIANT_FILE_STRAY', path }); continue; }
    // 링크·폴더·장치는 읽지 않는다(작품 밖 글을 판본으로 받지 않는다).
    if (!entry.isFile()) { errors.push({ code: 'VARIANT_FILE_INVALID', variant: id, path }); continue; }
    const nodeId = match[1];
    if (!tree.nodes.has(nodeId)) warnings.push({ code: 'VARIANT_NODE_MISSING', variant: id, nodeId, path });
    const { data, body } = parseDoc(await readFile(join(dir, entry.name), 'utf8'), { source: path });
    store.texts.set(nodeId, { nodeId, path, title: typeof data.title === 'string' ? data.title : null, data, body });
  }
  return store;
}

/**
 * 판본 본문을 읽는다(N6). variants/<판본 id>/<노드 id>.md 한 파일이 노드 하나의 그 판본 본문이다 — 트리 폴더와 떨어져 있어 노드를 옮기거나 묶어도 그대로다.
 * features.variants 가 꺼졌으면 읽지 않는다(빈 Map). 선언하지 않은 판본 폴더·트리에 없는 노드의 파일은 경고, 링크·깨진 용어 대응표는 오류다.
 * @param {string} root
 * @param {{ variants: string[], features: Record<string, boolean> }} config
 * @param {{ nodes: Map<string, any> }} tree
 */
export async function readVariants(root, config, tree) {
  /** @type {Map<string, VariantStore>} */
  const variants = new Map();
  const errors = [];
  const warnings = [];
  if (!config.features.variants) return { variants, errors, warnings };
  const top = await entryKind(join(root, VARIANTS_DIR));
  if (top !== null && top !== 'dir') return { variants, errors: [{ code: 'VARIANTS_DIR_INVALID', path: VARIANTS_DIR }], warnings };
  const declared = config.variants.filter((id) => id !== 'main');
  for (const entry of top ? await listEntries(join(root, VARIANTS_DIR)) : []) {
    if (!declared.includes(entry.name)) warnings.push({ code: 'VARIANT_DIR_UNDECLARED', path: `${VARIANTS_DIR}/${entry.name}` });
  }
  for (const id of declared) variants.set(id, await readVariantDir(root, id, tree, errors, warnings));
  return { variants, errors, warnings };
}

export const variantFilePath = (root, variant, nodeId) => join(root, VARIANTS_DIR, variant, `${nodeId}.md`);

/** 판본 본문을 쓴다(커밋만 부른다). 앞머리(title 등)는 그대로 두고 본문만 바꾼다. */
export async function writeVariantText(root, variant, nodeId, previous, body) {
  await writeFileAtomic(variantFilePath(root, variant, nodeId), serializeDoc({ data: previous?.data ?? {}, body }));
}
````

````js
 * 원고를 만드는 모델 요청은 원본(main 커밋 본문)과 용어 대응표를 싣는다(core/variants/payload.js). 커밋은 잠긴다(코어 잠금 씨앗).
 * 판본 검사는 stage 로 이 자리에 붙는다(packs/variants). main 파이프라인의 검사는 여기서 돌지 않고, 판본 검사는 main 에서 돌지 않는다.
 */
export const VARIANT_STEPS = Object.freeze([
  { id: 'draft', kind: 'generate', produces: 'draft' },
  { id: 'variant-checks', kind: 'check', tier: 'deterministic', stage: 'variant-checks' },
  { id: 'variant-review', kind: 'check', tier: 'model', stage: 'variant-review' },
  { id: 'revise', kind: 'generate', produces: 'draft', loop: { until: ['variant-checks'], max: 3 } },
  { id: 'approve', kind: 'gate' },
  { id: 'commit', kind: 'commit' },
]);
const STEP_IDS = VARIANT_STEPS.map((s) => s.id);

/**
 * 판본 파이프라인 digest 에 묶는 재료: 팩 digest + 판본 선언(id·종류·언어). 같은 단계라도 판본이 다르면 digest 가 다르다 —
 * 한 판본의 영수증은 다른 판본의 파이프라인과 맞지 않는다(LOCK_PIPELINE_MISMATCH).
 * @param {string|null} packDigest
 * @param {{ id: string, kind: string, lang: string|null }} spec
 */
export const variantPackDigest = (packDigest, spec) => sha256(canonicalJson({ packs: packDigest, variant: { id: spec.id, kind: spec.kind, lang: spec.lang } }));

/**
 * 선언된 판본마다 파이프라인. variants[].steps 는 있는 단계만 덮어쓴다(mode·reason·max). 새 단계·잠긴 단계 덮어쓰기는 거부한다.
 * 결과 파이프라인은 variant(판본 id)를 함께 든다.
 * @param {{ specs: Record<string, { id: string, kind: string, lang: string|null, steps: Record<string, any> }>, packDigest: string|null }} options
 */
export function resolveVariantPipelines({ specs, packDigest }) {
  const errors = [];
  /** @type {Record<string, any>} */
  const pipelines = {};
  for (const spec of Object.values(specs)) {
    const patches = {};
    for (const [id, patch] of Object.entries(spec.steps)) {
      if (STEP_IDS.includes(id)) patches[id] = patch;
      else errors.push({ code: 'VARIANT_STEP_UNKNOWN', variant: spec.id, stepId: id });
    }
    const result = resolvePipeline(VARIANT_STEPS, patches, { packDigest: variantPackDigest(packDigest, spec) });
    errors.push(...result.errors.map((error) => ({ ...error, variant: spec.id })));
    pipelines[spec.id] = { ...result, variant: spec.id };
  }
  return { pipelines, errors };
}

export const variantHomePipeline = () => resolvePipeline(VARIANT_STEPS, {});
````

````js
export function pickNextVariant(ctx, variant, runs) {
  const done = lastCommits(ctx.receiptRecords, variant);
  const latest = new Map();
  for (const run of runs) if (variantOf(run) === variant) latest.set(run.nodeId, run);
  for (const id of preorder(ctx.work.tree)) {
````

````js
import { sha256 } from '../util/hash.js';
import { lastCommits } from '../ledger/receipts.js';

/**
 * 판본이 기대는 원본(main)의 지금 커밋. 판본은 커밋된 원본에서만 만든다:
 * - 노드가 committed 이고 main 커밋 기록이 있어야 한다(아니면 VARIANT_ORIGINAL_NOT_COMMITTED).
 * - 파일 본문이 그 커밋 원고 그대로여야 한다(손수정이면 VARIANT_ORIGINAL_DRIFTED — 기록장에는 hash 만 있어 커밋 원고를 되살릴 수 없다).
 * @param {{ work: { tree: { nodes: Map<string, any> } }, receiptRecords: any[] }} ctx
 * @param {string} nodeId
 * @returns {{ error: string|null, text: string|null, original: { receiptId: string, committedHash: string }|null }}
 */
export function originalOf(ctx, nodeId) {
  const node = ctx.work.tree.nodes.get(nodeId);
  const commit = lastCommits(ctx.receiptRecords).get(nodeId);
  if (!node || !commit || node.status !== 'committed') return { error: 'VARIANT_ORIGINAL_NOT_COMMITTED', text: null, original: null };
  if (sha256(node.body) !== commit.committedHash) return { error: 'VARIANT_ORIGINAL_DRIFTED', text: null, original: null };
  return { error: null, text: node.body, original: { receiptId: commit.receiptId, committedHash: commit.committedHash } };
}

/** 이 판본의 지금 파일 본문(없으면 null). */
export const variantTextOf = (work, variant, nodeId) => work.variants?.get(variant)?.texts.get(nodeId) ?? null;
````

````js
import { FolioError } from '../errors.js';
````

````js
/**
 * 영수증의 판본과 파이프라인의 판본이 같아야 한다(main 파이프라인은 variant 가 없다 = main). 설정으로 끌 수 없다.

 */
export function assertPipelineVariant({ pipeline, receipt }) {
  if (variantOf(receipt) !== (pipeline?.variant ?? MAIN)) {
    throw new FolioError('LOCK_PIPELINE_MISMATCH', 'the receipt was issued for a different variant', { variant: String(variantOf(receipt)).slice(0, 60) });
  }
}

/**
 * 판본 커밋은 그 판본을 검사할 때 본 원본 커밋(receipt.original)이 지금도 원본의 마지막 커밋일 때만 된다(LOCK_ORIGINAL_CHANGED).
 * 기록장만 본다(원본 파일의 손수정은 원본의 drift 다). main 영수증은 해당 없음.
 * @param {any[]} receiptRecords
 * @param {any} receipt
 */
export function assertOriginalCurrent(receiptRecords, receipt) {
  if (variantOf(receipt) === MAIN) return;
  const commit = lastCommits(receiptRecords).get(receipt.nodeId);
  if (!commit || commit.receiptId !== receipt.original?.receiptId || commit.committedHash !== receipt.original?.committedHash) {
    throw new FolioError('LOCK_ORIGINAL_CHANGED', `${receipt.nodeId}: the original changed after this variant was checked`, {
      nodeId: receipt.nodeId, variant: receipt.variant,
    });
  }
}
````

````js
import { kindOf, markCounts } from './marks.js';

/**
 * 블록 표시 대조(variants.blocks-kept). 원본의 앵커 {#id}·참조 [[block:id]]·각주 [^id]·자료 인용 [[source:id]]를 판본과 견준다.
 * 판본에 모자라면 BLOCK_OMITTED(요약은 줄이는 것이라 보지 않는다), 원본보다 많으면 BLOCK_ADDED. 등급은 pack.yaml(advisory)과 작가 설정이 정한다.
 * @param {{ original?: string, draft?: string, variant?: { kind?: string } }} ctx
 */
export function blocksKept(ctx) {
  const kind = kindOf(ctx);
  if (!kind) return [];
  const before = markCounts(ctx.original);
  const after = markCounts(ctx.draft);
  const findings = [];
  for (const token of [...new Set([...before.keys(), ...after.keys()])].sort()) {
    const was = before.get(token) ?? 0;
    const now = after.get(token) ?? 0;
    if (now < was && kind !== 'summary') findings.push({ code: 'BLOCK_OMITTED', mark: token, message: `${token}: 원본 ${was}번, 판본 ${now}번` });
    if (now > was) findings.push({ code: 'BLOCK_ADDED', mark: token, message: `${token}: 원본 ${was}번, 판본 ${now}번` });
  }
  return findings;
}
````

````js
import { parseNodeMarks } from '../../../core/blocks/syntax.js';

/** 블록 표시를 종류:id 낱말로 센다(같은 표시가 여러 번이면 그만큼). */
export function markCounts(text) {
  const marks = parseNodeMarks(String(text ?? ''));
  const tokens = [
    ...marks.anchors.map((m) => `anchor:${m.id}`), ...marks.refs.map((m) => `ref:${m.target}`),
    ...marks.footnoteRefs.map((m) => `footnote:${m.id}`), ...marks.footnotes.map((m) => `note:${m.id}`),
    ...marks.citations.map((m) => `source:${m.sourceId}`),
  ];
  const counts = new Map();
  for (const token of tokens) counts.set(token, (counts.get(token) ?? 0) + 1);
  return counts;
}

/** 블록 표시를 지운 글 — 숫자를 셀 때 앵커 id(fig-3-2)·각주 번호를 숫자로 읽지 않게. */
export const withoutMarks = (text) => String(text ?? '').replace(/\{#[^}\n]*\}|\[\[[^\]\n]*\]\]|\[\^[^\]\n]*\]/g, ' ');
````

````js
import { numbersIn } from '../../sources/checkers/claims.js';
import { kindOf, withoutMarks } from './marks.js';

/**
 * 숫자 대조(variants.numbers-kept). 숫자 읽기는 sources 팩과 같다(아라비아 숫자, 천 단위 쉼표, 1.50 = 1.5). 블록 표시 속 숫자는 세지 않는다.
 * 원본의 숫자가 판본에 없으면 NUMBER_OMITTED(요약은 보지 않는다), 원본에 없는 숫자가 판본에 있으면 NUMBER_ADDED.
 * @param {{ original?: string, draft?: string, variant?: { kind?: string } }} ctx
 */
export function numbersKept(ctx) {
  const kind = kindOf(ctx);
  if (!kind) return [];
  const before = numbersIn(withoutMarks(ctx.original));
  const after = numbersIn(withoutMarks(ctx.draft));
  const findings = [];
  const omitted = kind === 'summary' ? [] : before.filter((n) => !after.includes(n));
  const added = after.filter((n) => !before.includes(n));
  if (omitted.length) findings.push({ code: 'NUMBER_OMITTED', numbers: omitted, message: `원본의 ${omitted.join(', ')}이(가) 판본에 없다` });
  if (added.length) findings.push({ code: 'NUMBER_ADDED', numbers: added, message: `${added.join(', ')}은(는) 원본에 없는 숫자다` });
  return findings;
}
````

````js
import { kindOf } from './marks.js';

/** 빈 줄로 나눈 문단(공백뿐인 것은 빼고). */
const paragraphs = (text) => String(text ?? '').replace(/\r\n/g, '\n').split(/\n\s*\n/).filter((p) => p.trim() !== '');

/**
 * 문단·분량(variants.paragraphs). 번역은 문단 수가 원본과 같아야 하고(PARAGRAPH_COUNT), 요약은 원본보다 짧아야 한다(SUMMARY_NOT_SHORTER).
 * 개정판은 문단을 고칠 수 있어 보지 않는다.
 * @param {{ original?: string, draft?: string, variant?: { kind?: string } }} ctx
 */
export function paragraphCount(ctx) {
  const kind = kindOf(ctx);
  if (kind === 'translation') {
    const was = paragraphs(ctx.original).length;
    const now = paragraphs(ctx.draft).length;
    return was === now ? [] : [{ code: 'PARAGRAPH_COUNT', was, now, message: `문단 수가 원본 ${was}, 판본 ${now}` }];
  }
  if (kind === 'summary') {
    const was = String(ctx.original).trim().length;
    const now = String(ctx.draft ?? '').trim().length;
    return now < was ? [] : [{ code: 'SUMMARY_NOT_SHORTER', was, now, message: `요약(${now}자)이 원본(${was}자)보다 짧지 않다` }];
  }
  return [];
}
````

````js
import { kindOf } from './marks.js';

/**
 * 용어 대응표(variants.terms). 대응 쌍은 판본 폴더 terms.yaml(코어가 ctx.terms 로 넘긴다).
 * - 번역: 원본에 원어(from)가 있는데 판본에 대응어(to)가 없으면 TERM_NOT_USED, 판본에 원어가 남아 있으면 TERM_LEFT.
 * - 개정·요약: 판본에 원어가 있고 대응어가 없으면 TERM_INCONSISTENT(대응표는 to 를 쓰라고 한다).
 * 대응어가 원어를 품으면(예: 마라 → 마라 언니) 원어가 남은 것으로 치지 않는다.
 * @param {{ original?: string, draft?: string, variant?: { kind?: string }, terms?: { from: string, to: string }[] }} ctx
 */
export function termsUsed(ctx) {
  const kind = kindOf(ctx);
  if (!kind || !Array.isArray(ctx.terms)) return [];
  const draft = String(ctx.draft ?? '');
  const findings = [];
  for (const { from, to } of ctx.terms) {
    const left = draft.includes(from) && !to.includes(from);
    if (kind === 'translation') {
      if (ctx.original.includes(from) && !draft.includes(to)) findings.push({ code: 'TERM_NOT_USED', term: from, message: `${from} → ${to}: 판본에 ${to}이(가) 없다` });
      if (left) findings.push({ code: 'TERM_LEFT', term: from, quote: from, message: `${from}이(가) 옮기지 않은 채 남았다(${to})` });
    } else if (left && !draft.includes(to)) {
      findings.push({ code: 'TERM_INCONSISTENT', term: from, quote: from, message: `대응표는 ${from} 대신 ${to}을(를) 쓴다` });
    }
  }
  return findings;
}
````

````js
import { sha256 } from '../util/hash.js';
import { lastCommits, receiptsById } from '../ledger/receipts.js';
import { preorder } from '../store/tree.js';
import { currentRev } from '../scope/stale.js';
import { checkReasons } from '../scope/stale-checks.js';
import { doneNodes } from '../run/done.js';
import { MAIN } from './model.js';
import { variantTextOf } from './original.js';

/**
 * 판본 하나의 상태: 그 판본 커밋만 본다(lastCommits(records, id)). 원본 상태(stale·drift)와 섞지 않는다.
 * - stale: 커밋 때 본 원본 원고·용어 대응표(refs)가 지금과 다르거나, 그 뒤 판본 검사가 켜지거나 바뀜. 표시만 하고 고치지 않는다 — 판본을 다시 돌린다.
 * - drift: 판본 파일이 커밋 원고와 다름(HAND_EDITED), 파일이 없어짐(VARIANT_FILE_MISSING), 노드가 트리에 없음(NODE_MISSING).
 * - missing: 원본은 끝났는데(doneNodes) 이 판본 커밋이 없는 잎(읽는 순서).
 */
function oneVariant({ work, receiptRecords, events, applied, done, variant }) {
  const commits = lastCommits(receiptRecords, variant);
  const receipts = receiptsById(receiptRecords);
  const stale = [];
  const drift = [];
  for (const [nodeId, commit] of commits) {
    if (!work.tree.nodes.has(nodeId)) { drift.push({ nodeId, code: 'NODE_MISSING' }); continue; }
    const text = variantTextOf(work, variant, nodeId);
    if (!text) drift.push({ nodeId, code: 'VARIANT_FILE_MISSING' });
    else if (sha256(text.body) !== commit.committedHash) drift.push({ nodeId, code: 'HAND_EDITED', path: text.path, expected: commit.committedHash, actual: sha256(text.body) });
    const receipt = receipts.get(commit.receiptId);
    if (!receipt) continue;
    const reasons = [];
    for (const ref of receipt.refs ?? []) {
      const now = currentRev({ work, events, ref, nodeId });
      if (now !== ref.rev) reasons.push({ ...ref, was: ref.rev, now });
    }
    reasons.push(...checkReasons({ applied: applied?.variants?.[variant] ?? null, had: receipt.appliedChecks }));
    if (reasons.length) stale.push({ nodeId, reasons });
  }
  const missing = preorder(work.tree).filter((id) => work.tree.nodes.get(id).kind === 'leaf' && done.has(id) && !commits.has(id));
  return { committed: commits.size, stale, drift, missing };
}

/**
 * folio_status 의 variants(N6): 선언된 판본마다 { committed, stale, drift, missing }. variants 기능이 꺼졌거나 판본이 없으면 null.
 * @param {{ work: any, receiptRecords: any[], events: any[], applied: any }} input
 */
export function variantsStatus({ work, receiptRecords, events, applied }) {
  const ids = work.config.variants.filter((id) => id !== MAIN);
  if (!work.config.features.variants || ids.length === 0) return null;
  const done = doneNodes(work, receiptRecords);
  return Object.fromEntries(ids.map((variant) => [variant, oneVariant({ work, receiptRecords, events, applied, done, variant })]));
}
````

````markdown
# 판본 (번역·개정·요약, `folio_run { variant }`)

판본은 커밋된 원본 잎 하나에서 만든 다른 글이다. 엔진은 판본을 원본과 견주고, 판본마다 따로 영수증을 남긴다. 원본 파일은 판본 커밋이 건드리지 않는다.

## 준비 (작가가 work.yaml에 적는다)

```yaml
packs: [novel, variants]          # 판본 검사를 쓰려면 둘째 팩으로 variants
checkSets: [novel.basic, variants.basic]
variants:
  - main
  - { id: en, kind: translation, lang: en }
  - { id: brief, kind: summary, lang: ko }
```

- `kind`: `translation`(번역)·`revision`(개정)·`summary`(요약). `id`는 소문자로 시작하는 영문·숫자·`-`(40자까지). `main`은 원본이다.
- 판본마다 `steps`로 판본 단계(`draft`·`variant-checks`·`variant-review`·`revise`·`approve`)의 `mode` 등을 바꿀 수 있다. 없는 단계를 적으면 `VARIANT_STEP_UNKNOWN`. `commit`은 잠겨 있다.
- 판본 글은 `variants/<id>/<노드 id>.md`에 있다. 노드를 옮기거나 묶어도 그대로다. 번역가가 먼저 둔 파일이 있으면 요청의 `current`로 실린다.
- 용어 대응표는 `variants/<id>/terms.yaml`: `terms: [{ from: 하나, to: Hana }]`. 요청의 `terms`로 실리고 `variants.terms` 검사가 본다.
- 기능 토글 `features.variants`(기본 켜짐). 끄면 `folio_run { variant }`가 `FEATURE_DISABLED`이고 `folio_status.variants`는 `null`이다. 잠금은 토글과 상관없다.

## 돌리기

1. 원본 잎을 먼저 커밋한다. 판본은 원본의 마지막 커밋 원고에서 시작한다.
2. `folio_run { root, variant: 'en' }`(다음 판본 노드) 또는 `{ root, node, variant: 'en' }`. 잎만, `mode`는 `normal`만 된다.
3. 요청에 답한다. 원고 요청(`produces: draft`)의 payload에는 `variant`(id·종류·언어), `original`(원본 글), `terms`, `current`, `instructions`가 있다. `instructions`대로 **판본 본문만** 답한다. 원본에 없는 사실·숫자를 더하지 않는다.
4. 검사 요청(`variant-review`)은 원본과 판본을 함께 본다(`variants.fidelity`). 지적에 판본 원고 인용이 있으면 넣는다(이 검사는 인용을 꼭 요구하지 않는다).
5. 승인하면 판본 파일만 쓰고 그 판본의 영수증이 남는다. 영수증에는 그때 본 원본 커밋(`original`)이 적힌다.

## 상태 — `folio_status`의 `variants`

`{ <판본 id>: { committed, stale, drift, missing } }`

- `missing`: 원본은 끝났는데 이 판본 커밋이 없는 잎(읽는 순서).
- `stale`: 커밋 뒤 원본이 다시 커밋됐거나(`reasons[].kind: original`) 용어 대응표가 바뀜(`terms`), 또는 판본 검사가 바뀜. 판본을 다시 돌린다. 엔진은 판본을 스스로 고치지 않는다.
- `drift`: 판본 파일을 손으로 고쳤거나(`HAND_EDITED`) 없어짐(`VARIANT_FILE_MISSING`), 노드가 트리에 없음(`NODE_MISSING`). 작가에게 알린다.
- 한 판본의 커밋·재검사는 다른 판본이나 원본의 상태에 섞이지 않는다.

## 검사 (`variants.basic`, 실험·참고 의견)

| 검사 | 종류 | 알리는 것 |
|---|---|---|
| `variants.blocks-kept` | 결정론 | 블록 앵커·참조·각주·자료 인용이 빠지거나 더해짐(요약은 빼도 된다) |
| `variants.numbers-kept` | 결정론 | 원본 숫자가 빠지거나 원본에 없는 숫자가 더해짐(요약은 빼도 된다) |
| `variants.paragraphs` | 결정론 | 번역의 문단 수가 다름, 요약이 원본보다 짧지 않음 |
| `variants.terms` | 결정론 | 용어 대응표를 따르지 않은 곳 |
| `variants.fidelity` | 모델 | 원본 대비 누락·추가·뜻 바뀜 |

- 판본 검사는 판본 실행에서만, 원본 검사는 원본 실행에서만 돈다. 참고 의견으로 판본을 고치지 않는다.

## 오류일 때

- `VARIANT_UNKNOWN`: work.yaml `variants`에 없는 판본이다. 선언은 작가가 한다.
- `VARIANT_ORIGINAL_NOT_COMMITTED`: 원본 잎을 먼저 커밋한다. `VARIANT_ORIGINAL_DRIFTED`: 원본 파일이 커밋 원고와 다르다 — `folio_run { mode: 'recommit' }`으로 원본을 다시 커밋하거나 작가가 되돌린다.
- `VARIANT_LEAF_ONLY`: 판본은 잎 글에만 만든다. `VARIANT_MODE_UNSUPPORTED`: 판본의 재검사·다시 커밋은 없다 — `mode: normal`로 판본을 다시 돌린다.
- `VARIANT_ORIGINAL_CHANGED`(질문 `blocking`): 판본 실행 도중 원본이 바뀌었다. 승인·고쳐 쓰기는 안 되고 `skip`만 된다. 그 뒤 판본을 다시 돌린다.
- `LOCK_ORIGINAL_CHANGED`(`folio_run`): 판본 영수증을 기록한 뒤 원본이 다시 커밋됐다. 작가의 이유를 받아 `folio_decide`의 `skip`으로 버리고 다시 돌린다.
- `CONFIG_INVALID`의 `VARIANTS_INVALID`·`VARIANT_UNSUPPORTED`(종류 없는 문자열 판본)·`VARIANT_ID_INVALID`·`VARIANT_DUPLICATE`·`VARIANT_KIND_INVALID`·`VARIANT_LANG_INVALID`·`VARIANT_FIELD_UNKNOWN`·`VARIANT_STEPS_INVALID`·`VARIANT_STEP_UNKNOWN`: work.yaml의 `variants`를 작가에게 고치게 한다.
- `WORK_INVALID`의 `VARIANTS_DIR_INVALID`·`VARIANT_DIR_INVALID`·`VARIANT_FILE_INVALID`·`VARIANT_TERMS_INVALID`: `variants/`나 그 안이 링크거나 용어 대응표 모양이 틀렸다. 작가에게 보통 폴더·보통 파일로 고치게 한다. 경고 `VARIANT_DIR_UNDECLARED`·`VARIANT_FILE_STRAY`·`VARIANT_NODE_MISSING`은 알리기만 한다.
````
