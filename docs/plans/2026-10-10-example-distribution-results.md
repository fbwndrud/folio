# 예시 배포 분리 검증 결과

## 구현

- MCP 패키지에는 기존 합성 입력과 실행기를 유지했다. 생성 작품은 `.local-output/example-distribution-20261010/`의 별도 배포물로 준비했다. 공개 업로드·commit·push는 실행하지 않았다.
- `scripts/example-bundle.js`는 명시적으로 고른 작품을 검사하고 사본을 만든다. 원고·자료·관리 이미지·상대 경로·기록장·실행 상태를 보존한다. SQLite 캐시와 잠금 파일, 호스트 통신 로그, 기존 export는 복사하지 않는다.
- 원본과 복사본의 파일 hash를 비교한다. 빌드 도중 원본이 바뀌면 중단한다. 손상된 원본·중단된 쓰기·링크·경로/토큰 노출·잘못된 승인 표기는 실패 처리한다. 기존 출력은 덮어쓰지 않는다.
- 사본에서 최신 Studio·Web·EPUB를 다시 생성했다. 원고와 기록장은 변경하지 않고 파생 화면에만 시연 상태를 표시했다.
- README·Studio 개요·설정·자료 전용 화면에 한국어/영어 예시 안내를 연결했다. 공개 다운로드 주소를 만들어 내지는 않았다.
- ZIP에 포함되는 `serve.mjs`는 Node.js만으로 실행되는 loopback 읽기 전용 서버다. 원고·기록장 경로와 작업 API는 제공하지 않는다.

## 준비된 배포물

| 종류 | 제목 | ZIP 크기(MiB) | 작성 구간 | 승인 상태 |
|---|---|---:|---:|---|
| 단편 | 비가 그친 뒤의 우편함 | 0.65 | 3 | 모의 승인 |
| 그림책 | 모모의 파란 공 | 26.41 | 2 | 모의 승인 |
| 안내서 | 첫 작품을 정리하는 작은 안내서 | 0.65 | 3 | 모의 승인 |
| 중편 | 파란 우편함의 여름 | 1.28 | 18 | 모의 승인 |
| 조사서 | AI 다음의 일 | 9.04 | 80 | 실제 작가 승인 대기 |

각 ZIP에는 `work/`, `studio/`, `web/`, `epub/`, README, manifest, 전용 서버가 함께 들어 있다. 이미지가 없는 작품은 추가 이미지를 생성하지 않았다. 그림책은 삽화 2장, 조사서는 표지 1장을 보존했다.

## 실제 검증

- 다섯 ZIP을 로컬 HTTP에서 내려받았다. 조사서 ZIP은 Codex 브라우저의 실제 다운로드 파일을 검사했다.
- 다른 폴더 `.local-output/example-download-verification-20261010/`에 풀고, ZIP checksum·CRC와 포함 파일 716개의 hash를 확인했다. 최상위 manifest 5개는 ZIP checksum/CRC로 검증한다.
- 다섯 EPUB의 CRC·시연 상태 표시를 확인했다. 복사된 작품 106개 작성 구간의 Studio 원고 hash와 추적 원본 hash가 일치했다.
- 모든 사본의 `inspectWork` 진단을 통과했다. 실제 stdio MCP의 `folio_status`, `folio_assets(list)`로 다시 연결했다. 기록장 검증을 통과했고 조사서는 `awaiting_user`를 유지했다. 새로운 승인 호출은 하지 않았다.
- 관리 이미지 3장의 실제 바이트 hash가 원본과 일치했다.
- 브라우저에서 모음의 한국어/영어 전환, 다운로드, 그림책 Studio/예시 안내, 조사서 승인 대기와 표지 표시를 확인했다. 그림책 원고와 예시 안내는 390px 화면에서 가로 넘침이 없었다. 그림책 이미지와 조사서 표지가 실제로 로딩됐다.
- 백엔드 전체 1,739개, 화면 67개 테스트 통과. 중단된 쓰기 거부를 추가 확인한 배포 회귀 테스트 3개도 통과했다. lint·typecheck·diff 검사를 통과했다.
- tarball 설치 검증을 통과했다. 패키지에는 생성 ZIP/EPUB/PNG, `.local-output`, 작품 기록장이 없으며 기존 합성 예시·그림·추적·production 검증이 설치본에서도 동작했다.

## 남은 공개 배포 결정

공개 저장소 remote가 설정되어 있지 않으며 콘텐츠 라이선스는 미지정이다. Folio 엔진의 Apache-2.0과 작품 콘텐츠 라이선스는 구분한다. 이 산출물은 공개 릴리스의 준비본이며 공개 게시 완료 선언이 아니다. 모의 승인과 같은 호스트의 자기검토는 실제 작가 채택·독립 품질 인증을 의미하지 않는다.

## 증거 위치

생성 파일은 모두 `.local-output/`에 유지한다. 배포 모음의 `catalog.json`, `SHA256SUMS`, 작품별 manifest와 별도 검증 폴더의 `verification.json`, `work-verification.json`, `mcp-verification.json`에 바이트·작품·실제 MCP 연결 결과를 보존했다. 화면 증거는 배포 폴더의 `gallery-preview.jpg`, `gallery-desktop.jpg`, `picturebook-mobile.jpg`다.
