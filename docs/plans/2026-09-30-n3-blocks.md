# Folio N3 블록·상호 참조 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 본문 속 그림·표·식 앵커에 장별 번호를 매기고, 각주 번호, 참고문헌, 색인을 파일에서 다시 만드는 투영으로 낸다. `folio_find`의 `blocks`·`bibliography`·`terms`와 `folio_status`의 `blocks`로 보여 주고, 지식 책 팩에 상호 참조 검사(실험, 참고)를 더한다. M6b 뷰어가 쓸 조회 함수 이름을 `core/index/query.js`에 고정한다. N1의 싼 미룬 minor를 같이 고친다.

**Architecture:**
- 새 폴더 `core/blocks/`에 순수 함수 여섯 파일을 둔다. 모델·네트워크·파일 쓰기가 없다. 입력은 `openWork` 결과와 호출자가 읽어 넘긴 기록장 줄이다.
  - `syntax.js`: 본문 표시 읽기(앵커·블록 참조·각주·자료 인용, 줄·글자 위치)
  - `numbering.js`: 블록 번호(장별)
  - `footnotes.js`: 각주 번호(노드별)
  - `subtree.js`: 가지 범위
  - `catalog.js`: 블록 목록·문제(+ `folio_status` 요약)
  - `bibliography.js`: 참고문헌(본문 인용 + N2 근거 연결)
  - `term-index.js`: 색인(이름 스캔 + 앞머리 선언 + M4 등장 위치)
- 번호·색인은 저장하지 않는다. 저장 정본은 본문 앵커다. `index.db` 표는 바꾸지 않는다.
- `core/index/query.js`가 조회 함수를 다시 내보내 이름을 고정한다(M6b 계약). index.db·작업 잠금 없이 도는 함수다(M6 V10과 같은 길).
- 도구는 `folio_find` query enum 끝에 셋(`blocks`, `bibliography`, `terms`)을 더한다. `folio_status`에 `blocks`를 더한다.
- 상호 참조 검사는 코어 잠금이 아니다. 지식 책 팩 검사 `knowledge.cross-refs`(experimental advisory)와 새 세트 `knowledge.references`(추천만)다.
- 새 기능 토글은 `blocks`, `bibliography`, `termIndex` 셋이다(끝에 추가, 기본 켜짐, 부모 없음, 실행 digest 밖).

**Tech Stack:** Node ESM + JSDoc, `node:test`, `node:sqlite`(기존 index만), `yaml`, `@modelcontextprotocol/sdk`(1.x, stdio), ESLint 9 + TypeScript(`checkJs`).

## 설계 요약

### 본문 표시

| 표시 | 뜻 | 규칙 |
|---|---|---|
| `{#fig-1-1}` | 블록 앵커(M1) | id는 작품 전체에서 하나. 앞머리(첫 `-` 앞)가 `fig`·`tbl`·`eq`면 번호 종류(그림·표·식). 그 밖(`{#intro}`)은 번호 없는 이름 앵커 |
| `[[block:id]]` | 블록 참조(M1) | 가리키는 앵커가 없으면 `BLOCK_REF_BROKEN` |
| `[^id]` / 줄머리 `[^id]: 글` | 각주 참조·정의(GFM) | 정의는 한 줄, 줄머리 공백 세 칸까지. id는 노드 안에서 하나 |
| `[[source:id]]` | 자료 인용(새) | `sources/` 설명서 id. 없으면 `SOURCE_CITATION_BROKEN` |

- 앵커가 있는 줄에서 앵커를 뺀 글이 제목(`caption`, 200자까지)이다.
- 코드 블록(울타리) 안은 읽지 않는다(`core/util/fences.js`, M1과 같은 규칙).
- `parseNodeMarks`는 항목마다 줄 번호와 본문 안 글자 위치 `[start, end)`를 준다. 뷰어가 본문 조각을 나눌 때 쓴다.

### 번호 규칙

- 읽는 순서(트리 전위)로 종류마다 따로 센다.
- 무리 = 잎 바로 위 레벨(교재의 장)의 본문(`role: body`) 노드. 무리 번호는 그 레벨 본문 노드의 차례다. 부가 바뀌어도 이어 센다. 블록 번호는 `무리.n`(예: `그림 2.1`).
- 무리 밖(서문·부록, 레벨이 하나인 작품)은 종류마다 따로 `n`(예: `표 1`).
- 주인 앵커만 번호를 받는다. 주인은 M1 `validateBlocks`의 `anchors`(id가 처음 나온 곳)다. 겹친 뒤 정의는 번호 없이 `BLOCK_DUPLICATE`로 남는다.
- 각주 번호는 노드마다 처음 참조된 차례(GFM). 정의가 둘이면 앞의 것을 쓴다.
- 번호는 투영이다. 노드를 옮기면(`folio_structure move`) 파일의 앵커는 그대로이고 번호만 바뀐다(D2 N3-5).

### 참고문헌·색인

- **참고문헌:** 실제로 인용한 자료만 싣는다. 인용은 두 가지다.
  - 본문 `[[source:id]]`(있는 자료만)
  - N2 근거 연결. 주장을 지금 본문에서 다시 찾았고(`located`·`relocated`) 자료 인용이 지금 자료에 있는(`verified`) 것만 센다.
  - 번호는 처음 인용된 읽는 순서다(노드 → 줄 → 본문 인용이 근거보다 앞). 가지를 주면 그 안에서 새로 매긴다(장별 참고문헌).
  - 자료 설명서와 근거 기록을 읽기만 한다.
- **색인:** 엔티티마다 그것이 나오는 본문 잎 노드(`kind: leaf`, `role: body`)를 읽는 순서로 준다.
  - 나옴 = 이름·별칭 스캔(`core/index/scan.js`, index.db와 같은 규칙) 또는 앞머리 `entities` 선언 또는 기록된 등장 위치(M4, 다시 찾은 것만).
  - 계획(가지 노드)·서문·부록은 넣지 않는다. 약속(`promise`)은 기본으로 뺀다(`kinds`로 고를 수 있다).
  - 순서는 이름(NFC) 코드 순이다. 한글 음절은 가나다 순이다.

### 상호 참조 검사 (`knowledge.cross-refs`)

- 결정론, `stage: facts`, `severity: advisory`, `experimental: true`, `requiresOrder` 없음(뒤 절 그림을 미리 가리켜도 된다).
- 원고가 노드 본문을 대신한다. 앵커는 다른 노드 본문과 원고에서 찾는다. 이 노드의 옛 본문은 보지 않는다.
- 지적: `BLOCK_REF_BROKEN`, `BLOCK_DUPLICATE`(다른 노드에 있거나 원고 안에서 겹침), `FOOTNOTE_UNDEFINED`·`FOOTNOTE_UNUSED`·`FOOTNOTE_DUPLICATE`, `SOURCE_CITATION_BROKEN`.
  - `quote`는 원고에 그대로 있는 표시 글이다.
  - 같은 코드·같은 인용은 한 번만 알리고 메시지에 횟수를 적는다.
  - 지적에 `severity`를 적지 않는다(S 규칙: 등급은 `pack.yaml`과 작가 설정).
- 세트 `knowledge.references`(검사 하나). `recommendedFor: { kinds: [textbook, history, guide] }`. `knowledge.basic`에는 넣지 않는다(팩 yaml은 추가만).

### 도구·상태·기능

- `folio_find { query: 'blocks' | 'bibliography' | 'terms', id }`.
  - `id`는 노드 id(그 노드와 자손) 또는 `'*'`(작품 전체)다. 노드 id 규칙(`^[a-z0-9][a-z0-9-]*$`)상 `'*'`은 노드일 수 없다. 둘 다 아니면 `NODE_NOT_FOUND`. `required`는 그대로다.
  - `blocks`는 파일에서 바로 계산한다(잠금 없음, `node`·`entity`처럼).
  - `bibliography`·`terms`는 기록장을 읽으므로 작업 잠금 안에서 읽는다. 기록장이 깨졌으면 던지지 않는다: `ledger: { ok: false, line }`과 파일만으로 된 답(N2 결정 19). 기능이 꺼져 기록장을 안 봤으면 `ledger: null`.
- `folio_status.blocks = { problems, total }`. `blocks` 기능이 꺼지면 `null`. 기록장이 깨져 일찍 돌아가는 모양에는 넣지 않는다(`occurrences`·`evidence`와 같다).
- 기능 `blocks`, `bibliography`, `termIndex`: 기본 켜짐, 부모 없음, `RUN_FEATURES` 밖(읽기 전용 투영이라 실행이 묻는 것·검사 범위를 바꾸지 않는다). 끄면 그 질문이 `FEATURE_DISABLED`. 상호 참조 검사는 기능이 아니라 세트로 고른다.
- 요청 payload는 바꾸지 않는다. 호스트는 원고를 쓰기 전에 `folio_find blocks`로 id와 번호를 본다(D1 문서).

### M6b 계약 — `core/index/query.js`

M6b B5(블록 화면)와 N8(내보내기)이 쓴다. 이름과 인자 모양은 바꾸지 않는다. 바꾸려면 쓰는 레인의 테스트와 같은 커밋에서 바꾼다. 모두 `openWork` 결과에서 바로 계산한다. index.db도 작업 잠금도 쓰지 않는다. 기록장은 호출자가 읽어 넘긴다(M6a `readLedgerView`의 `records`, 깨졌으면 `null`). 기능 확인(`blocks`·`bibliography`·`termIndex`)은 호출자가 한다.

| 이름 | 모양 |
|---|---|
| `blockCatalog(work, { nodeId? })` | `{ blocks: [{ id, kind, number, label, nodeId, line, caption, refs: [{ nodeId, line }] }], refs: [{ nodeId, line, target, valid, label }], footnotes: [{ nodeId, id, number, line, text, refs: [line] }], citations: [{ nodeId, line, sourceId, valid }], problems: [{ code, nodeId, line, id? \| target? \| sourceId? }] }` |

## Global Constraints

- 이름 `Folio`, MCP 도구 접두어 `folio_`, 작품 내부 폴더 `.folio/`.
- `package.json` `"engines": { "node": "^22.13.0 || ^24.0.0 || ^26.0.0" }`, `"type": "module"`. 런타임 의존성은 `yaml`과 `@modelcontextprotocol/sdk` 둘뿐이다. 늘리지 않는다. 네이티브 모듈은 금지다. 이 계획은 `package.json`을 바꾸지 않는다.
- 엔진은 모델을 부르지 않는다. `core/`와 `packs/`는 모델·네트워크를 부르지 않고, 동적 `import()`도 쓰지 않는다(`test/core/no-model-calls.test.js`). `core/blocks/*`는 파일도 쓰지 않는다(읽기 전용 투영).
- 서버는 `test/server/tools.test.js` `BANNED` 목록(커밋 경로, 구조 쓰기, `core/ledger/ledger.js`, `core/store/tree.js`, file-tx, `core/store/sources.js`, `core/evidence/record-run.js`)을 직접 import하지 않는다. B1은 기록장을 `core/view/ledgers.js`로 읽는다.
- 잠금 규칙은 설정·팩·세트·기능 토글 어느 것으로도 끌 수 없다.
  - 커밋 원고 hash = 검사 원고 hash
  - 영수증 없이 커밋 금지
  - hard 차단
  - 기록장은 추가만
  - 같은 호스트 자기검토를 독립 평가로 표기 금지
  - soft·참고 의견은 자동 수정 사유 아님
  - `core.promise-order`는 어떤 세트·토글에서도 돈다
- 이 계획은 잠금 경로를 고치지 않는다. 새 코드는 쓰지 않고 읽기만 한다. C1의 검사기 변경은 더 엄격해지기만 한다(조용한 통과 → `CHECK_CRASHED`).

- 도구 목록, features, 팩 목록, 가드 목록, `folio_find` query enum, 팩 yaml의 검사·세트는 끝에만 추가한다. 목록 테스트는 같은 커밋에서 고친다. 기존 assert는 약화하지 않는다.

`core/blocks/syntax.js` (56줄):

````js
import { fencedLines } from '../util/fences.js';
import { BLOCK_ANCHOR, BLOCK_REF } from '../store/blocks.js';

/**
 * 번호를 매기는 블록 종류: 앵커 id 의 앞머리(첫 '-' 앞) → 이름. 그 밖의 앵커({#intro})는 이름만 있는 앵커다(번호 없음, 참조는 된다).
 * 얼린 목록이다 — 종류를 더할 때는 끝에만 더한다.
 */
export const BLOCK_KINDS = Object.freeze({ fig: '그림', tbl: '표', eq: '식' });

const ID = '[A-Za-z0-9][\\w-]*';
/** 줄머리(공백 세 칸까지)의 각주 정의 `[^id]: 글`. GFM 과 같은 모양이고 한 줄짜리만 읽는다(CRLF 의 \r·U+2028 도 줄 안 글로 받는다). */
const FOOTNOTE_DEF = new RegExp(`^ {0,3}\\[\\^(${ID})\\]:[ \\t]*([\\s\\S]*)$`);
const FOOTNOTE_REF = new RegExp(`\\[\\^(${ID})\\]`, 'g');
/** 본문 속 자료 인용 `[[source:id]]`. 가리키는 자료는 sources/ 설명서의 id 다. */
const CITATION = new RegExp(`\\[\\[source:(${ID})\\]\\]`, 'g');
const CAPTION_MAX = 200;

/** 앵커 id 의 번호 종류(fig·tbl·eq). 알려진 앞머리가 아니면 null. */
export function blockKind(id) {
  const prefix = String(id).split('-')[0];
  return Object.hasOwn(BLOCK_KINDS, prefix) ? prefix : null;
}

/** 앵커가 있는 줄에서 앵커를 뺀 글(공백 하나로 모음, 200자까지). 그림·표 제목 자리다. */
const captionOf = (text) => text.replace(BLOCK_ANCHOR, ' ').replace(/\s+/g, ' ').trim().slice(0, CAPTION_MAX);

/**
 * 노드 본문 하나의 블록 표시를 모두 읽는다. 줄 번호는 1부터다. 코드 블록(울타리) 안은 읽지 않는다(core/store/blocks.js 와 같은 규칙).
 * - anchors: `{#id}` — kind(번호 종류 또는 null), caption(그 줄의 글).
 * - refs: `[[block:id]]`.
 * - footnoteRefs: `[^id]`(각주 정의 줄의 머리는 참조가 아니다), footnotes: 줄머리 `[^id]: 글`.
 * - citations: `[[source:id]]`.
 * 모든 항목에 start·end: 본문 안 글자 위치 [start, end)(표시 글 자체. 각주 정의는 `[^id]:`부터 줄 끝까지) — 뷰어가 본문 조각을 나눌 때 쓴다.
 * 순서는 줄, 같은 줄에서는 나온 순서다. 검사·번호 매기기는 이 결과만 본다.
 * @param {string} body
 */
export function parseNodeMarks(body) {
  const fenced = fencedLines(body);
  const out = { anchors: [], refs: [], footnoteRefs: [], footnotes: [], citations: [] };
  let offset = 0;
  String(body).split('\n').forEach((text, index) => {
    const line = index + 1;
    const at = offset;
    offset += text.length + 1;
    if (fenced.has(line)) return;
    const span = (match, base = at) => ({ start: base + match.index, end: base + match.index + match[0].length });
    for (const match of text.matchAll(BLOCK_ANCHOR)) out.anchors.push({ id: match[1], line, kind: blockKind(match[1]), caption: captionOf(text), ...span(match) });
    for (const match of text.matchAll(BLOCK_REF)) out.refs.push({ target: match[1], line, ...span(match) });
    const definition = FOOTNOTE_DEF.exec(text);
    if (definition) out.footnotes.push({ id: definition[1], line, text: definition[2].trim(), start: at + text.indexOf('[^'), end: at + text.length });
    const rest = definition ? definition[2] : text;
    for (const match of rest.matchAll(FOOTNOTE_REF)) out.footnoteRefs.push({ id: match[1], line, ...span(match, at + text.length - rest.length) });
    for (const match of text.matchAll(CITATION)) out.citations.push({ sourceId: match[1], line, ...span(match) });
  });
  return out;
}
````

````js
import { markedNodes, numberAnchors } from './numbering.js';
import { numberFootnotes } from './footnotes.js';
import { subtreeOf } from './subtree.js';

/**
 * 블록 목록(N3 계약, core/index/query.js 가 이름을 고정해 내보낸다). 파일에서 바로 계산한다 — index.db·작업 잠금 없이.
 * - blocks: 주인 앵커를 읽는 순서로. { id, kind, number, label, nodeId, line, caption, refs: [{ nodeId, line }] }.
 *   refs 는 작품 어디서든 그 블록을 가리키는 참조다(범위를 좁혀도 전부).
 * - refs: 범위 안 블록 참조. { nodeId, line, target, valid, label }(label 은 대상의 번호 이름, 없으면 null).
 * - footnotes: 범위 안 노드의 각주(core/blocks/footnotes.js). citations: 범위 안 자료 인용 { nodeId, line, sourceId, valid }.
 * - problems: BLOCK_DUPLICATE·BLOCK_REF_BROKEN(M1 validateBlocks), FOOTNOTE_*, SOURCE_CITATION_BROKEN. 읽는 순서 → 줄 → 코드 순.
 * nodeId 를 주면 그 노드와 자손만(없는 노드는 NODE_NOT_FOUND). 번호는 늘 작품 전체 기준이다.
 * @param {any} work openWork 결과
 * @param {{ nodeId?: string }} [options]
 */
export function blockCatalog(work, { nodeId } = {}) {
  const inScope = subtreeOf(work.tree, nodeId);
  const nodes = markedNodes(work);
  const numbers = numberAnchors(work, nodes);
  const order = new Map(nodes.map(({ node }, index) => [node.id, index]));
  const refsTo = new Map();
  for (const { node, marks } of nodes) {
    for (const ref of marks.refs) {
      if (!refsTo.has(ref.target)) refsTo.set(ref.target, []);
      refsTo.get(ref.target).push({ nodeId: node.id, line: ref.line });
    }
  }
  const out = { blocks: [], refs: [], footnotes: [], citations: [], problems: [] };
  for (const { node, marks, owned } of nodes) {
    if (inScope && !inScope.has(node.id)) continue;
    for (const anchor of owned) {
      const numbered = numbers.get(anchor.id);
      out.blocks.push({
        id: anchor.id, kind: numbered?.kind ?? null, number: numbered?.number ?? null, label: numbered?.label ?? null,
        nodeId: node.id, line: anchor.line, caption: anchor.caption, refs: refsTo.get(anchor.id) ?? [],
      });
    }
    for (const ref of marks.refs) {
      out.refs.push({ nodeId: node.id, line: ref.line, target: ref.target, valid: work.blocks.anchors.has(ref.target), label: numbers.get(ref.target)?.label ?? null });
    }
    const notes = numberFootnotes(node.id, marks);
    out.footnotes.push(...notes.footnotes);
    out.problems.push(...notes.problems);
    for (const citation of marks.citations) {
      const valid = work.sources.has(citation.sourceId);
      out.citations.push({ nodeId: node.id, line: citation.line, sourceId: citation.sourceId, valid });
      if (!valid) out.problems.push({ code: 'SOURCE_CITATION_BROKEN', nodeId: node.id, sourceId: citation.sourceId, line: citation.line });
    }
  }
  out.problems.push(...work.blocks.problems.filter((problem) => !inScope || inScope.has(problem.nodeId)));
  out.problems.sort((a, b) => order.get(a.nodeId) - order.get(b.nodeId) || a.line - b.line || (a.code < b.code ? -1 : a.code > b.code ? 1 : 0));
  return out;
}
````

````js
/**
 * 노드 하나의 각주 번호(GFM 과 같은 규칙). 번호는 노드 안에서 처음 참조된 차례대로 1부터다.
 * - 같은 id 의 정의가 둘 이상이면 앞의 것을 쓰고 뒤의 것마다 FOOTNOTE_DUPLICATE.
 * - 정의가 없는 참조는 나올 때마다 FOOTNOTE_UNDEFINED. 참조가 없는 정의는 FOOTNOTE_UNUSED(번호 없음).
 * 오류로 막지 않고 문제로 돌려준다(core/store/blocks.js validateBlocks 와 같은 방식).
 * @param {string} nodeId
 * @param {{ footnoteRefs: Array<{ id: string, line: number }>, footnotes: Array<{ id: string, line: number, text: string }> }} marks core/blocks/syntax.js parseNodeMarks 결과
 */
export function numberFootnotes(nodeId, marks) {
  const definitions = new Map();
  const problems = [];
  for (const definition of marks.footnotes) {
    if (definitions.has(definition.id)) problems.push({ code: 'FOOTNOTE_DUPLICATE', nodeId, id: definition.id, line: definition.line });
    else definitions.set(definition.id, definition);
  }
  const notes = new Map();
  for (const ref of marks.footnoteRefs) {
    const definition = definitions.get(ref.id);
    if (!definition) { problems.push({ code: 'FOOTNOTE_UNDEFINED', nodeId, id: ref.id, line: ref.line }); continue; }
    if (!notes.has(ref.id)) notes.set(ref.id, { nodeId, id: ref.id, number: notes.size + 1, line: definition.line, text: definition.text, refs: [] });
    notes.get(ref.id).refs.push(ref.line);
  }
  for (const definition of definitions.values()) {
    if (!notes.has(definition.id)) problems.push({ code: 'FOOTNOTE_UNUSED', nodeId, id: definition.id, line: definition.line });
  }
  return { footnotes: [...notes.values()], problems };
}
````

````js
import { preorder } from '../store/tree.js';
import { BLOCK_KINDS, parseNodeMarks } from './syntax.js';

/** 번호 무리 레벨: 잎 바로 위 레벨(교재의 장). 레벨이 하나뿐이면 null — 작품 전체를 한 줄로 센다. */
export const numberingLevel = (config) => (config.levels.length >= 2 ? config.levels.at(-2).name : null);

/**
 * 읽는 순서(트리 전위)로 노드마다 블록 표시를 읽는다. owned 는 그 노드가 주인인 앵커다:
 * 작품 전체에서 id 가 처음 나온 곳(core/store/blocks.js validateBlocks 의 anchors, M1 규칙)만 주인이고, 겹친 앵커의 뒤 정의는 빠진다.
 * @param {{ tree: any, blocks: { anchors: Map<string, { nodeId: string, line: number }> } }} work
 */
export function markedNodes(work) {
  const seen = new Set();
  return preorder(work.tree).map((id) => {
    const node = work.tree.nodes.get(id);
    const marks = parseNodeMarks(node.body);
    const owned = marks.anchors.filter((anchor) => {
      const owner = work.blocks.anchors.get(anchor.id);
      if (!owner || owner.nodeId !== id || owner.line !== anchor.line || seen.has(anchor.id)) return false;
      seen.add(anchor.id);
      return true;
    });
    return { node, marks, owned };
  });
}

/**
 * 블록 번호(투영). 저장하지 않고 파일에서 언제든 다시 만든다. 앵커 id 는 번호와 상관없다.
 * - 종류(fig·tbl·eq)마다 따로 센다. 이름만 있는 앵커는 번호가 없다.
 * - 무리: 잎 바로 위 레벨의 본문(role: body) 노드. 무리 번호는 그 레벨 본문 노드의 읽는 순서 차례(부가 바뀌어도 이어 센다).
 *   블록은 자기 또는 조상 중 무리 노드를 찾아 "무리.n"(예: 1.2). 무리 밖(서문·부록, 레벨 하나짜리 작품)은 종류마다 따로 "n".
 * @param {{ config: { levels: Array<{ name: string }> }, tree: { nodes: Map<string, any> } }} work
 * @param {ReturnType<typeof markedNodes>} nodes
 * @returns {Map<string, { kind: string, number: string, label: string }>} 앵커 id → 번호
 */
export function numberAnchors(work, nodes) {
  const level = numberingLevel(work.config);
  const groups = new Map();
  if (level) for (const { node } of nodes) if (node.level === level && node.role === 'body') groups.set(node.id, groups.size + 1);
  const groupOf = (node) => {
    for (let at = node; at; at = at.parentId ? work.tree.nodes.get(at.parentId) : null) if (groups.has(at.id)) return at.id;
    return null;
  };
  const counters = new Map();
  const out = new Map();
  for (const { node, owned } of nodes) {
    const group = groupOf(node);
    for (const anchor of owned) {
      if (anchor.kind === null) continue;
      const key = `${group ?? ''}\u0000${anchor.kind}`;
      const n = (counters.get(key) ?? 0) + 1;
      counters.set(key, n);
      const number = group ? `${groups.get(group)}.${n}` : String(n);
      out.set(anchor.id, { kind: anchor.kind, number, label: `${BLOCK_KINDS[anchor.kind]} ${number}` });
    }
  }
  return out;
}
````

````js
import { FolioError } from '../errors.js';

/**
 * 노드 하나와 그 자손 id(Set). nodeId 가 없으면(undefined·null) null — 작품 전체다.
 * 없는 노드면 NODE_NOT_FOUND. 블록·참고문헌·색인 조회를 가지 하나로 좁힐 때 쓴다.
 * @param {{ nodes: Map<string, { children: string[] }> }} tree
 * @param {string|null|undefined} nodeId
 * @returns {Set<string>|null}
 */
export function subtreeOf(tree, nodeId) {
  if (nodeId === undefined || nodeId === null) return null;
  if (typeof nodeId !== 'string' || !tree.nodes.has(nodeId)) throw new FolioError('NODE_NOT_FOUND', String(nodeId).slice(0, 200));
  const ids = new Set();
  const walk = (id) => { ids.add(id); for (const child of tree.nodes.get(id).children) walk(child); };
  walk(nodeId);
  return ids;
}
````

````js
import { preorder } from '../store/tree.js';
import { evidenceStates } from '../evidence/state.js';
import { parseNodeMarks } from './syntax.js';
import { subtreeOf } from './subtree.js';

const byText = (a, b) => (a < b ? -1 : a > b ? 1 : 0);
/** 글자 위치 → 줄 번호(1부터). */
const lineAt = (text, offset) => String(text).slice(0, offset).split('\n').length;

/**
 * 참고문헌(N3 계약, core/index/query.js 가 이름을 고정해 내보낸다). 이 작품이 실제로 인용한 자료만 싣는다.
 * - 인용 = 본문 `[[source:id]]`(있는 자료만) + 근거 연결(N2 기록장). 근거 연결은 주장을 지금 본문에서 다시 찾았고(located·relocated)
 *   자료 인용이 지금 자료에 있는(verified) 것만 센다 — 다시 찾지 못한 주장은 folio_status evidence.stale 이 알린다.
 * - 번호는 처음 인용된 읽는 순서(노드 → 줄 → 본문 인용이 근거 연결보다 앞)로 1부터. citedIn 은 { nodeId, via: 'citation'|'evidence' } 를 읽는 순서로, 겹치지 않게.
 * - 자료 설명서와 근거 기록을 읽기만 한다. 기록장은 호출자가 읽어 넘긴다. evidenceRecords 가 null 이면 근거 연결을 보지 않고 evidence: false.
 * nodeId 를 주면 그 가지의 인용만 보고 번호도 그 안에서 새로 매긴다(장별 참고문헌). 없는 노드는 NODE_NOT_FOUND.
 * @param {any} work openWork 결과
 * @param {{ evidenceRecords?: any[]|null, nodeId?: string }} [options]
 */
export function bibliography(work, { evidenceRecords = null, nodeId } = {}) {
  const inScope = subtreeOf(work.tree, nodeId);
  const order = new Map(preorder(work.tree).map((id, index) => [id, index]));
  const cites = [];
  for (const id of order.keys()) {
    if (inScope && !inScope.has(id)) continue;
    for (const citation of parseNodeMarks(work.tree.nodes.get(id).body).citations) {
      if (work.sources.has(citation.sourceId)) cites.push({ sourceId: citation.sourceId, nodeId: id, line: citation.line, via: 'citation' });
    }
  }
  for (const state of evidenceRecords === null ? [] : evidenceStates(work, evidenceRecords)) {
    if (state.status === 'stale' || (inScope && !inScope.has(state.nodeId))) continue;
    const line = lineAt(work.tree.nodes.get(state.nodeId).body, state.start);
    for (const link of state.sources) {
      if (link.verified && work.sources.has(link.sourceId)) cites.push({ sourceId: link.sourceId, nodeId: state.nodeId, line, via: 'evidence' });
    }
  }
  cites.sort((a, b) => order.get(a.nodeId) - order.get(b.nodeId) || a.line - b.line || byText(a.via, b.via));
  const entries = new Map();
  for (const cite of cites) {
    if (!entries.has(cite.sourceId)) {
      const source = work.sources.get(cite.sourceId);
      entries.set(cite.sourceId, {
        number: entries.size + 1, sourceId: source.id, title: source.title, date: source.date, reliability: source.reliability, file: source.file, citedIn: [],
      });
    }
    const entry = entries.get(cite.sourceId);
    if (!entry.citedIn.some((c) => c.nodeId === cite.nodeId && c.via === cite.via)) entry.citedIn.push({ nodeId: cite.nodeId, via: cite.via });
  }
  return { entries: [...entries.values()], evidence: evidenceRecords !== null };
}
````

````js
import { preorder } from '../store/tree.js';
import { scanMentions } from '../index/scan.js';
import { occurrenceStates } from '../occurrences/state.js';
import { PROMISE_KIND } from '../promise.js';
import { subtreeOf } from './subtree.js';

const byText = (a, b) => (a < b ? -1 : a > b ? 1 : 0);
const nfc = (text) => String(text).normalize('NFC');

/**
 * 색인(N3 계약, core/index/query.js 가 이름을 고정해 내보낸다). 엔티티마다 그것이 나오는 본문 잎 노드를 읽는 순서로.
 * - 나옴 = 이름·별칭 스캔(index.db 와 같은 규칙: core/index/scan.js, 긴 말 먼저, 코드 블록 제외) 또는 앞머리 entities 선언
 *   또는 기록된 등장 위치(M4, 지금 본문에서 다시 찾은 것만). 위치마다 { nodeId, title, count, declared, marks }.
 * - 인쇄되는 본문만 가리킨다: 잎 노드이고 role: body. 계획(가지 노드)·서문(front)·부록(back)은 넣지 않는다.
 * - kinds 를 주면 그 종류만, 없으면 약속(promise)을 뺀 모든 종류. 나오는 곳이 없는 엔티티는 빠진다.
 * - 순서: 이름(NFC) 코드 순 → id 순(한글 음절은 가나다 순이다).
 * occurrenceRecords 가 null 이면 기록된 등장 위치를 보지 않는다(occurrences 기능이 꺼졌거나 기록장을 못 읽음).
 * nodeId 를 주면 그 가지만(장별 색인). 없는 노드는 NODE_NOT_FOUND.
 * @param {any} work openWork 결과
 * @param {{ occurrenceRecords?: any[]|null, nodeId?: string, kinds?: string[] }} [options]
 */
export function termIndex(work, { occurrenceRecords = null, nodeId, kinds } = {}) {
  const inScope = subtreeOf(work.tree, nodeId);
  const entities = [...work.entities.values()];
  const wanted = (entity) => (Array.isArray(kinds) ? kinds.includes(entity.kind) : entity.kind !== PROMISE_KIND);
  const marked = new Map();
  for (const mark of occurrenceRecords === null ? [] : occurrenceStates(work, occurrenceRecords)) {
    if (mark.status === 'stale' || mark.surface.kind !== 'node') continue;
    const key = `${mark.entityId}\u0000${mark.surface.id}`;
    marked.set(key, (marked.get(key) ?? 0) + 1);
  }
  const locations = new Map(entities.filter(wanted).map((entity) => [entity.id, []]));
  for (const id of preorder(work.tree)) {
    const node = work.tree.nodes.get(id);
    if (node.kind !== 'leaf' || node.role !== 'body' || (inScope && !inScope.has(id))) continue;
    const counts = scanMentions(node.body, entities);
    for (const [entityId, list] of locations) {
      const count = counts.get(entityId) ?? 0;
      const declared = node.entities.includes(entityId);
      const marks = marked.get(`${entityId}\u0000${id}`) ?? 0;
      if (count > 0 || declared || marks > 0) list.push({ nodeId: id, title: node.title, count, declared, marks });
    }
  }
  const entries = entities.filter((entity) => locations.get(entity.id)?.length > 0)
    .map((entity) => ({ entityId: entity.id, name: entity.name, kind: entity.kind, locations: locations.get(entity.id) }))
    .sort((a, b) => byText(nfc(a.name), nfc(b.name)) || byText(a.entityId, b.entityId));
  return { entries };
}
````

````js
import { parseNodeMarks } from '../../../core/blocks/syntax.js';
import { numberFootnotes } from '../../../core/blocks/footnotes.js';
import { workEntities } from './definitions.js';

/** 각주 문제 → 원고에 그대로 있는 표시 글. */
const FOOTNOTE_QUOTES = Object.freeze({
  FOOTNOTE_UNDEFINED: (id) => `[^${id}]`,
  FOOTNOTE_UNUSED: (id) => `[^${id}]:`,
  FOOTNOTE_DUPLICATE: (id) => `[^${id}]:`,
});
const FOOTNOTE_MESSAGES = Object.freeze({
  FOOTNOTE_UNDEFINED: (id) => `각주 [^${id}]의 정의([^${id}]: 글)가 이 원고에 없다`,
  FOOTNOTE_UNUSED: (id) => `각주 정의 [^${id}]를 부르는 곳이 이 원고에 없다`,
  FOOTNOTE_DUPLICATE: (id) => `각주 [^${id}]를 두 번 이상 정의했다 — 앞의 것만 쓴다`,
});

/**
 * 상호 참조 유효성(knowledge.cross-refs, N3). 이 원고의 블록 참조·앵커·각주·자료 인용이 가리키는 것이 있는지 본다.
 * - 원고가 이 노드 본문을 대신한다: 앵커는 다른 노드 본문(ctx.work)과 이 원고에서 찾는다. 이 노드의 옛 본문은 보지 않는다.
 * - BLOCK_REF_BROKEN: `[[block:id]]`가 가리키는 앵커가 어디에도 없다. BLOCK_DUPLICATE: 원고의 앵커 id 가 다른 노드에 이미 있거나 원고 안에서 겹친다.
 * - FOOTNOTE_UNDEFINED·FOOTNOTE_UNUSED·FOOTNOTE_DUPLICATE: 원고 안 각주(core/blocks/footnotes.js 와 같은 규칙).
 * - SOURCE_CITATION_BROKEN: `[[source:id]]`가 sources/ 에 없는 자료를 가리킨다.
 * - quote 는 원고에 그대로 있는 표시 글이다. 같은 코드·같은 인용은 한 번만 알리고 횟수를 메시지에 적는다. 코드 블록 안은 보지 않는다.
 * - 순서와 무관하다(뒤 절의 그림을 미리 가리켜도 된다 — requiresOrder 없음).
 * - 등급은 pack.yaml(advisory)과 작가 설정이 정한다. 지적에 severity 를 적지 않는다. ctx.work 가 없으면 던진다(workEntities).
 * @param {{ draft?: string, node?: { id: string }, nodeId?: string, work?: any }} ctx
 */
export function crossRefs(ctx) {
  workEntities(ctx);
  const { work } = ctx;
  const nodeId = ctx.node?.id ?? ctx.nodeId ?? null;
  const marks = parseNodeMarks(typeof ctx.draft === 'string' ? ctx.draft : '');
  const elsewhere = new Set();
  for (const node of work.tree.nodes.values()) {
    if (node.id !== nodeId) for (const anchor of parseNodeMarks(node.body).anchors) elsewhere.add(anchor.id);
  }
  const found = new Map();
  const add = (code, quote, target, message) => {
    const key = `${code}\u0000${quote}`;
    if (found.has(key)) found.get(key).times += 1;
    else found.set(key, { code, quote, target, message, times: 1 });
  };
  const here = new Set();
  for (const anchor of marks.anchors) {
    if (elsewhere.has(anchor.id) || here.has(anchor.id)) add('BLOCK_DUPLICATE', `{#${anchor.id}}`, anchor.id, `앵커 {#${anchor.id}}의 id 가 이미 있다 — 블록 id 는 작품 전체에서 하나다`);
    here.add(anchor.id);
  }
  for (const ref of marks.refs) {
    if (!elsewhere.has(ref.target) && !here.has(ref.target)) add('BLOCK_REF_BROKEN', `[[block:${ref.target}]]`, ref.target, `[[block:${ref.target}]]가 가리키는 앵커 {#${ref.target}}가 작품에 없다`);
  }
  for (const problem of numberFootnotes(nodeId, marks).problems) {
    add(problem.code, FOOTNOTE_QUOTES[problem.code](problem.id), problem.id, FOOTNOTE_MESSAGES[problem.code](problem.id));
  }
  for (const citation of marks.citations) {
    if (!work.sources.has(citation.sourceId)) add('SOURCE_CITATION_BROKEN', `[[source:${citation.sourceId}]]`, citation.sourceId, `[[source:${citation.sourceId}]]가 가리키는 자료가 sources/ 에 없다`);
  }
  return [...found.values()].map(({ code, quote, target, message, times }) => ({ code, quote, target, message: times > 1 ? `${message} (${times}번)` : message }));
}
````

````js
/** MCP 너머의 가짜 호스트 모델. drafts: 노드 id → 원고. 검사는 지적 없이 답하고, 수정 요청에는 같은 원고를 돌려준다. */
function answerer(drafts = {}) {
  return (request) => {
    const p = request.payload;
    if (request.purpose === 'check') return JSON.stringify({ checked: p.checks.map((c) => c.checkId), findings: [] });
    if (request.purpose === 'revise' || request.purpose === 'user_revision') return p.draft;
    if (p.produces === 'plan') return `${p.node.title || p.node.id} 계획`;
    if (p.produces === 'draft') return drafts[p.node.id] ?? `${p.node.title || p.node.id} 본문.`;
    if (p.produces === 'events') return JSON.stringify({ events: [], appearances: [], mentions: [] });
    throw new Error(`no answer for ${request.purpose}/${p.produces}`);
  };
}

async function ok(promise) {
  const out = await promise;
  assert.equal(out.ok, true, JSON.stringify(out.error));
  return out.result;
}

/** until 을 만날 때까지 run/resume/decide(approve) 를 MCP 로 돌린다. */
async function drive(folio, root, start, answer, until) {
  const labels = [];
  let out = await ok(folio.call('folio_run', { root, ...start }));
  for (let i = 0; i < 60; i += 1) {
    labels.push(label(out));
    if (until(out)) return { labels, out };
    if (out.status === 'needs_model') {
      out = await ok(folio.call('folio_resume', { root, runId: out.runId, answers: Object.fromEntries(out.requests.map((r) => [r.requestId, answer(r)])) }));
    } else if (out.status === 'needs_user') {
      out = await ok(folio.call('folio_decide', { root, runId: out.runId, action: 'approve' }));
    } else throw new Error(`unexpected ${out.status}`);
  }
  throw new Error('drive did not finish');
}
````
