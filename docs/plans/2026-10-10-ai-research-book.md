# 대규모 AI 리서치 책 실습

기준일: 2026-10-10. 최신 1차 자료를 조사하고 실제 Folio MCP로 자료·구조·근거·삽화를 등록한다. 생성 원고와 연구 자료는 `.local-output/ai-research-book-20261010/`에만 보관한다.

## 목표

중심 질문은 AI가 답변 도구에서 작업 시스템으로 진화할 때 무엇을 믿고 어떻게 준비할지다. 능력, 작업 위임, 멀티모달, 오픈 모델, 생산성, 경제성·전력, 신뢰성, 정책, 미래 시나리오와 독자 실행안을 다룬다. 긴 원고와 다수의 자료·인용을 함께 관리하는 사용 사례를 검증한다.

## 진행 순서

1. 독립 연구 작업 두 개로 공식 보고서·논문·문서 원문을 확인한다. 출처별 발행일, 관측 시점, 검색 시점, 수치 조건과 한계를 보존한다.
2. 조사 결과에 맞춰 장·절 목차와 자료 목록을 확정한다. 관측·기업 주장·추론·조건부 전망을 구별한다.
3. 공개 MCP를 통해 작품, 구조, 자료, 자료 인용 및 이미지 자산을 등록한다. 호스트가 작성한 원고 파일은 공개 문서 형식으로 초안 상태로 보관한다. 원고 등록에 파일 편집을 사용한 부분을 보고한다.
4. 실제 작가 승인 없이 채택을 기록하지 않는다. 실행·승인 동작 시험은 별도의 합성 시험 사본에서만 모의 승인한다. 실제 책은 검토용 초안으로 내보낸다.
5. 원고별 인용 연결, 인용 원문 일치, 누락·중복·깨진 링크, 장·절 순서, 이미지 hash, 재접속 및 내보내기 본문 일치를 검사한다.
6. Folio Studio와 Web·EPUB을 열어 첫·중간·마지막 절, 자료 상세, 긴 목차, 한국어 표시와 모바일 화면을 확인한다. 저장 데이터 검사와 실제 화면 검사를 별도로 기록한다.

## 완료 조건

- 이전 중편(18절·26,721자)보다 충분히 큰 독립 내용과 다수의 검증된 출처를 갖춘다. 실제 규모를 보고하며 목표량을 채우기 위한 문단 반복은 하지 않는다.
- 모든 등록 절과 모든 인용·근거를 데이터로 검사한다. 사실 정확성에 대한 기계적 인용 일치와 연구 검토를 혼동하지 않는다.
- Studio·Web 책·EPUB과 결과 보고서를 제공한다. 사용자 승인 대기와 같은 호스트 자기검토를 명확히 표시한다.
- 결함이 나오면 합성 재현 fixture와 필요한 회귀 테스트로 수정한다. 대규모 작품 생성 성공을 동시 사용자 성능·전체 프로덕션 검증으로 확대 해석하지 않는다.

## 마이그레이션·롤백

기존 작품과 저장 형식은 변경하지 않는다. 새 ignored 폴더와 새 출력 폴더만 사용한다. 코드 수정이 필요해지면 기존 작업 변경을 보존하고 수정한 파일만 추적한다. 생성물 실패 시 해당 실습 폴더를 격리해 재실행하며 기존 내보내기는 덮지 않는다.
