# Studio 판본 선택 업데이트

영어 예시 실습에서 확인한 main 전용 Studio를 보완한다. 기존 main 조회와 기록장 형식을 유지하면서 선택 판본의 본문·검토·출판을 연결하는 최소 조회 기능을 추가한다.

- 선언된 판본 목록과 별도 읽기 API를 제공한다. 요청은 ID만 받고 파일 경로를 받지 않는다.
- 미작성 번역은 빈 본문과 미작성 표시를 제공한다. 원문을 번역으로 대체 표시하지 않는다.
- 검토 영수증은 선택 판본의 커밋만 읽으며 원본 바인딩·stale·drift·미확인 상태를 보존한다. 조회로 승인이나 기록을 만들지 않는다.
- 번역용 별도 트리에서 블록·그림·용어 이름을 읽는다. 원본의 인물 설정·추적·주장은 번역 검증으로 오인하지 않게 표시한다.
- 살아 있는 Studio와 새 정적 사본에서 판본을 선택한다. 이전 정적 사본은 main 조회를 유지한다.
- 출판 미리보기와 Web/EPUB 다운로드가 같은 판본을 사용한다. 번역 누락은 다운로드를 거부하고 원문·용어 변경은 경고한다.
- 일관된 읽기 체크포인트로 정적 사본을 만들고 번역에서만 쓰인 이미지도 포함한다.

테스트는 합성 fixture에 원본·번역 커밋을 만든다. 판본 간 영수증 분리, 누락, 수동 변경, 원문 변경, 꺼진 기능, 알 수 없는 판본, 깨진 기록장, 다운로드 언어, 이전 snapshot 호환을 확인한다. 영어 예시의 실제 사본도 브라우저에서 원본/번역을 전환해 확인한다. 기존 공개 파일·태그를 덮지 않고 개선된 번역 Studio 예시를 별도 파일로 제공한다. 엔진 버전 변경·원본 데이터 마이그레이션은 포함하지 않는다.
