# Studio 판본 선택 검증 결과

선택한 판본의 본문·구간 영수증·출판을 연결했다. 원고·기록장 포맷 변경이나 데이터 마이그레이션 없이 main 조회는 기본값으로 유지한다. 판본 목록과 읽기 API, 살아 있는 Studio와 새 정적 사본의 선택기가 추가됐다.

- 판본 ID만 받고 경로나 외부 원본은 받지 않는다. 기존 loopback·토큰·읽기 전용 경계를 유지한다.
- 번역 누락은 빈 구간과 안내를 보여 주며 책 내보내기는 거부한다. 원문을 번역 대신 넣지 않는다.
- 판본별 커밋·영수증·원본 연결·손수정·다시 확인 필요 상태를 분리한다. 손상된 기록장은 읽기를 거부하거나 기존 검증 실패 응답을 유지한다.
- 블록과 용어 이름은 임시 읽기 투영에서 처리한다. 원본·판본 파일은 수정하지 않는다. 작품 전체 설정·목차·자료·추적·검토 요약이 원본 기준임을 표시한다.
- 원문·용어표 변경은 출판 경고에 포함한다. 다운로드가 현재 판본을 사용해도 승인이나 최신 번역을 자동으로 보장하지 않는다.
- 정적 사본은 체크포인트를 다시 확인하고 번역 전용 인라인 그림을 포함한다. 이전 snapshot은 원본 조회를 유지한다.

합성 수용 테스트 5개는 본문/영수증 연결, 원본 바이트 보존, 누락·손수정·원문/용어 변경, 알 수 없는 ID·꺼진 기능·손상된 기록장, 판본 전용 그림, HTTP 인증·읽기 전용·다운로드를 검증한다. 화면 테스트 3개는 판본별 경로와 이전 정적 사본 호환을 확인한다. 예시 제목 테스트는 선택한 판본만 바꾸고 영수증 내용 지문과 HTML 경계를 보존하는지 확인한다.

macOS arm64 / Node 24.19.0에서 전체 백엔드 1,762개, 화면 70개가 먼저 통과했다. 이후 구간 제목 표시와 합성 예시 제목 테스트를 추가했으며 관련 테스트 12개와 화면 70개를 다시 통과했다. 공개 소스 사본에서도 전체 백엔드 1,762개·화면 70개와 패키지 검증이 통과했다. lint·typecheck와 Studio 빌드도 통과했다. 기존 관계도 분할 파일의 크기 경고는 남아 있다.

실제 영어 예시 사본에서 브라우저로 원본 → 번역, 구간 영수증의 원본 버전, 번역 출판 미리보기와 제목을 확인했다. 살아 있는 Studio의 Web/EPUB 버튼은 준비 완료를 표시했다. 브라우저 다운로드 이벤트의 파일 경로 확보는 도구 시간 제한에 걸려 확인하지 못했으므로, 같은 인증 HTTP API로 원본·번역의 Web/EPUB 네 파일을 받아 본문과 언어 메타데이터를 검증했다. 파일 저장 완료까지 브라우저 이벤트로 확인했다고 주장하지 않는다.

영어 예시 5개를 새 Studio로 다시 묶고 작품별 파일 hash·ZIP/EPUB CRC·언어·판본 메타데이터를 확인했다. 작품·생성 그림·실습 출력은 소스에 커밋하지 않는다. 모의 승인과 같은 호스트의 자기검토 안내는 보존한다. 기존 0.1.0 태그·엔진·예시 자산을 교체하지 않고 새 모음과 번역 Studio ZIP을 별도 배포한다. 현재 소스와 새 예시의 기능을 최초 엔진 묶음의 기능으로 표현하지 않는다.

GitHub hosted CI의 기존 실행 환경 제약은 해결하지 않았다. 원격 OS/Node 매트릭스 통과로 표현하지 않는다. 새 모델 실행·이미지 생성·작가의 실제 채택·독립 번역 품질 인증도 수행하지 않았다.
