## 작업 중 판정 전체

아래 판정은 순서대로 보존한다. 상세 검토·시험 증거는 main의 `.superpowers/sdd/n7-branching-evidence/`에 보존한다.

Ruling: 최신 사용자 ‘이후 다음 작업들도 끝까지 진행해’를 N7 추천 설계와 N7/J4 및 N8 로컬 구현·검토·통합 승인으로 해석한다. 원격 배포는 포함하지 않는다. 비용: 설계 선택이 의도와 다르면 로컬 커밋을 수정해야 한다.
Ruling: 정본 외부 아티팩트 접근 불가. 승인된 로컬 N7 설계와 로드맵을 근거로 삼는다. 비용: 외부 정본의 미확인 세부 사항은 일치 검증하지 못한다.
Ruling: 전체 코드를 계획에 넣기 위해 추적된 소스의 별도 일반 복사본에서 시험한다. 복사본은 .git이 없으며 실제 구현 브랜치 소스는 수정하지 않는다. 비용: 실행 단계에서 동일 코드를 다시 검증한다.
Ruling: 경로 refs와 전체 그래프 refs를 분리한다. main의 분기 노드 재검사는 새 refs를 기준으로 stale을 해소하되 다른 기존 노드 refs의 의미를 바꾸지 않는다. 비용: 분기 재검사 refs 전체가 최신 기준이 된다.
Ruling: 경로 지적 넘김 식별에 선택적 pathId·entityId를 포함한다. 기존 지적은 두 필드 모두 없으면 기존 의미를 유지한다. 비용: 필드를 추가한 기존 외부 지적의 넘김 범위가 좁아진다.
Ruling: 게임북 가지 fit/review는 gamebook.parent-fit/structure-review의 실험 참고 검사로 제공한다. 잎 경로 검사와 별도 stage를 사용하기 때문이다. 비용: 새 팩 검사는 설계 표의 다섯 검사보다 두 개 많다.
Ruling: 그래프 진단·팩 검사 지적은 200개로 제한하고 절단 사유를 남긴다. 악성 메타데이터가 무제한 결과를 만들지 않게 한다. 비용: 모든 문제를 한 번에 보려면 순차적으로 수정해야 한다.
Ruling: 독립 검토의 두 한도 결함은 계획 제공 코드의 결함이다. 수치·순수 인터페이스는 유지하고 반환 경로 전체 바이트와 scope 진단 상한을 수정한다. 사건을 비워도 경로 메타데이터가 못 들어가면 경로를 절단하고 미완료 이유를 남긴다. 비용: 큰 작품은 더 적은 경로를 한 번에 받는다. 진단은 마지막 항목에 절단 이유를 예약한다.
Ruling: 최신 main 재검사가 분기 refs 또는 명시 분기 문맥을 새로 얻었으면 그 재검사 refs를 기준으로 선택한다. 최초 영수증만 보는 계획 코드가 설계의 변경 감지 계약을 위반했다. 기존 linear/none만 유지되는 커밋의 refs 의미는 보존한다. 비용: 분기로 전환한 기존 커밋은 정상 재검사로 참고 기준이 갱신된다.
Ruling: 최신 경로 사건 또는 초안의 알 수 없는 vital/exists 값은 해당 상태를 unknown으로 바꾸고 BRANCH_STATE_UNKNOWN 참고 지적을 남긴다. 과거 dead/destroyed로 확정 지적하는 계획 코드가 미검증 상태 비확정 계약을 위반했다. 비용: 불명확한 최신 상태가 있는 경로는 작가가 명시 상태를 보완할 때까지 생사·존재 충돌을 확정하지 않는다.
